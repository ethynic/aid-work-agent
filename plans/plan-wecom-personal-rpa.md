## 风险与回退

| 风险 | 触发条件 | 回退方案 |
|------|---------|---------|
| PC 桌面会话不可见 | 锁屏、RDP 断开、分辨率变化 | 自动暂停账号，人工恢复桌面后再继续 |
| Phase 1 漏抓率 > 5% | 人工抽样核对不达标 | 优先改消息监听；仍不达标则提前接入会话存档或评估 Android 虚拟机备选 |
| 搜索结果重名导致串话风险 | 搜索结果无法唯一确定会话 | 停止自动发送，进入人工绑定确认 |
| Phase 1 出现账号限制 | 7 天测试期触发风控或异常登录 | 立即停止，复盘操作频率、网络出口、登录设备；必要时放弃该账号 PC 托管 |
| 会话存档 SDK 接入困难 | RSA 解密 / C 库调用问题 | 继续人工抽样，但不得宣称自动可证明低漏抓 |
| 多账号 Windows 运维成本过高 | 故障恢复、人力巡检超过预期 | 对关键账号评估 Android 虚拟机路线；低价值账号降级为只读或人工 |
| Android 虚拟机被识别或兼容性差 | 企微登录失败、频繁异常、无障碍不可用 | 不切云手机 / 真机，回退 PC RPA 或官方只读方案 |

## 关键依赖

- **Windows 执行环境**：低成本 PC / Windows VM / 云桌面，必须保持可见桌面会话。
- **企微版本**：必须固定到 Worker 测试通过的版本。
- **远控与桌面保持方案**：VNC / 物理控制台 / 云桌面能力，不能依赖断开后 UI 消失的 RDP 会话。
- **法务**：员工授权书、用户协议、隐私政策审查。
- **现有基础设施**：可观测性体系（[observability-design.md](../docs/system/infrastructure/observability-design.md)）、Redis、PostgreSQL。
