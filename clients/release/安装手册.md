# 招聘智能体 · 同事电脑安装手册

> 拿到一个文件夹（或压缩包），里面有下列文件，按本手册从上到下做一遍即可，全程约 15 分钟。
> 全程**不需要**管理员权限；装完后日常使用不需要打开任何命令行窗口。

| 文件 | 用途 |
|---|---|
| `agent-tool-runtime-0.2.9.tgz` | 安装包（BOSS 直聘操作能力已内含，只需装这一个） |
| `start_runtime.bat` | 后台运行脚本（第 6 步用） |
| `register_runtime_task.ps1` | 开机自启注册脚本（第 6 步用） |
| `collect_logs.bat` / `collect_logs.ps1` | 日志采集：双击 bat 生成桌面「诊断包.zip」发管理员 |
| `VERSION.txt` | 版本信息 |
| `安装手册.md` | 本手册 |

---

## 第 1 步：安装 Node.js（一次性，已有旧版也必须升级）

> ⚠️ **电脑上已装过 Node 的注意**：本工具要求 **Node 20 或更高**（老版本如 v16.x 无法运行，
> 安装时 npm 也会提示 unsupported）。升级就是重新安装：下载 LTS 安装包一路下一步覆盖即可，
> 不需要先卸载。开发团队用的就是 v24，放心装最新的。

1. 打开 https://nodejs.org → 下载 **LTS 版本**（当前是 24.x；20 / 22 / 24 都可以）
2. 双击安装，**一路点下一步**，全部默认即可
3. 验证：按 `Win + R` 键，输入 `cmd` 回车，在黑窗口里输入：
   ```
   node -v
   ```
   显示 `v20` 及以上（如 v24.13.0）即成功；若还显示旧版本号，重开一个 cmd 窗口再试，仍不对就重装一遍

> 电脑上已有 Chrome 浏览器即可，无需另装。

## 第 2 步：安装工具包

还是在 cmd 黑窗口里，输入 `npm install -g ` 注意后面留一个空格，然后把 `agent-tool-runtime-0.2.9.tgz` **直接拖进黑窗口**（自动补全完整路径），回车：

```
npm install -g C:\...\agent-tool-runtime-0.2.9.tgz
```

验证：输入 `aid-runtime status`，能看到配置目录与「未配对」之类信息即成功（未配对是正常的，第 5 步解决）。

## 第 3 步：首次使用时登录一次 BOSS（无需任何手工配置）

Chrome 调试实例**会在首次使用时自动弹出**：你（或智能体）第一次执行任何 BOSS 操作时，
工具会自动启动一个专用的 Chrome 窗口并打开 BOSS 直聘（数据独立保存在 `C:\chrome-debug`，
与日常 Chrome 互不影响）。**你只需要在这个弹出的窗口里登录一次 BOSS 账号**（登录态会一直保留）。

最快的触发方式：配对完成（第 5 步）后在企业微信里对招聘智能体说「打开 BOSS 直聘」，
弹出窗口后扫码登录即可。

> 极少数情况自动拉起失败（如 Chrome 装在非常规路径），可手动兜底：桌面新建快捷方式，目标填
> `"C:\Program Files\Google\Chrome\Application\chrome.exe" --remote-debugging-port=9222 --user-data-dir="C:\chrome-debug"`，
> 用它打开 Chrome 并登录 BOSS（此后一直用这个快捷方式）。

## 第 4 步：拿配对码（找管理员）

联系管理员，在 Web 管理端「本地工具 / 设备管理」页**生成配对码**（8 位大写字母数字，**5 分钟内有效、只能用一次**，拿到后立刻做第 5 步）。

## 第 5 步：配对并启动

cmd 里执行（把 `<配对码>` 换成刚拿到的码，名字按实际填）：

```
aid-runtime pair --code <配对码> --server https://agent2.aidingyi.cn --name "张三-办公电脑"
aid-runtime start
```

看到 `[runtime] 已启动 device_id=...` 即成功，管理员那边设备页会显示**在线（绿色）**。
按 `Ctrl + C` 停掉这个窗口（第 6 步会换成无窗口后台运行）。

## 第 6 步：后台常驻 + 开机自启（免窗口免手动）

1. 把文件夹里的 `start_runtime.bat` 复制到 `C:\Users\<你的用户名>\AppData\Roaming\aidwork-tool-runtime\` 文件夹里
   （快捷方式：`Win + R` 输入 `%APPDATA%\aidwork-tool-runtime` 回车直接打开该文件夹）
2. 把文件夹里的 `register_runtime_task.ps1` 复制到桌面（或任意位置）
3. cmd 里执行（路径按实际存放位置调整）：
   ```
   powershell -ExecutionPolicy Bypass -File C:\Users\<你的用户名>\Desktop\register_runtime_task.ps1
   ```
   提示「已注册并启动后台任务」即成功。以后开机自动运行，无需任何操作。

> 日志在 `%APPDATA%\aidwork-tool-runtime\logs\runtime.log`（支持排障时用）。

## 第 7 步：验收清单（全部打勾即完成）

- [ ] `node -v` 显示 v20 或更高（如 v24.x）
- [ ] `aid-runtime status` 正常
- [ ] 触发过一次 BOSS 操作，Chrome 自动弹出且已登录 BOSS
- [ ] 配对成功，设备页显示在线
- [ ] 开机自启已注册
- [ ] 综合自检：cmd 执行 `aid-runtime doctor`，各项全部 OK

之后日常使用：**保持那个专用 Chrome 窗口开着并处于登录状态**（不开也没关系，智能体会自动
把它拉起来；只要别退出里面的 BOSS 登录），直接在企业微信里对招聘智能体说话即可（如「帮我筛选简历」）。

## 可选：安装 RapidOCR 提升简历识别精度（推荐，不装也能用）

智能体读取简历时需要 OCR 识别文字。**不装任何东西也能用**（自动用 Windows 自带识别，
但中文错字较多）；花 5 分钟装下面的组件后识别质量明显更好（错字大幅减少）：

1. 打开 https://www.python.org/downloads/ → 下载 **Windows installer (64-bit)**，双击安装，
   第一屏**务必勾选 "Add python.exe to PATH"**，其余一路下一步
2. 按 `Win + R` 输入 `cmd` 回车，在黑窗口输入（一行）：
   ```
   pip install rapidocr-onnxruntime==1.4.4 Pillow
   pip install onnxruntime-directml==1.20.1
   ```
   等待安装完成（约 100MB，全程离线可用，不需要管理员权限）。第二条是可选的 GPU 加速
   （普通办公机的核显即可，无需独立显卡），OCR 识别约 3 倍提速，建议安装
3. 验证：cmd 里执行 `aid-runtime doctor`，看到「OCR 引擎（简历读取）✅ RapidOCR …
   DirectML GPU 加速，单次推理实测 X.Xs」即成功；显示「CPU」也能用，只是批量读简历稍慢；
   显示「WinRT 兜底」也不影响使用，只是识别质量略差

> 说明：安装/卸载该组件都不影响其他功能；识别引擎自动选择（装了用好的，没装用系统自带的）。
> 排障时如需强制退回系统识别，找管理员设置环境变量 `AID_BOSS_OCR_ENGINE=winrt`；
> Python 装在非常规位置导致探测不到时，设 `AID_BOSS_RAPIDOCR_PY=<python.exe 完整路径>`。

## 常见问题

| 现象 | 处置 |
|---|---|
| npm install 提示 EBADENGINE / unsupported | Node 版本低于 20，回第 1 步升级 Node 后重装 |
| doctor 显示「OCR 引擎：WinRT 兜底」 | 不影响使用（系统识别兜底）；想提升简历识别精度按「可选：安装 RapidOCR」一节安装 |
| BOSS 操作时 Chrome 没自动弹出 | Chrome 装在非常规路径或未安装；用第 3 步的手动快捷方式兜底 |
| doctor 报「CDP 端点可连」失败 | 手动方式兜底（见第 3 步）；自动拉起在真正执行操作时才会发生，doctor 只检查 |
| doctor 报「无 BOSS 登录态」 | 在专用 Chrome 里重新登录 zhipin.com |
| 设备页显示离线 | 重启电脑（自启任务会拉起）；或手动跑第 6 步的 ps1 |
| 报「桌面不可交互 / DESKTOP_NOT_INTERACTIVE」 | 电脑锁屏或断开了远程桌面（断开 RDP 会锁屏）。解锁屏幕保持登录即可；远程运维建议断开前保持目标机会话不锁屏 |
| pair 报配对码无效 | 码超 5 分钟过期，找管理员重新生成 |
| 执行打招呼/筛选失败 | 多为页面弹确认层或风控拦截，人工看一眼 Chrome 页面；不要连续重试 |
| 提示「该职位无开聊权益」 | BOSS 账号权益问题，换职位或开通权益 |

**注意事项**：智能体操作期间（筛选/打招呼约 2-3 分钟）请勿移动鼠标、勿遮挡该 Chrome 窗口；多人共用电脑时每人用自己的 Windows 账户各自安装配对。

遇到手册外的问题：双击文件夹里的 **`collect_logs.bat`**，约 1 分钟后桌面会出现「aidwork-诊断包-日期.zip」，把它发给管理员即可（内含运行日志、配置、doctor 全链路检查结果；不含任何凭证，可放心外发）。
