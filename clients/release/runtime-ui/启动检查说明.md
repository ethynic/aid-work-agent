# Runtime 启动检查（只读）

用于界面显示「本机管理记录或系统保护不可用（代码11）」且管理连接没有建立的情况。已有r4无需再次重装；这个工具只收集启动所需的文件状态，不修复或清空配置。

1. 将检查ZIP解压到普通文件夹，用日常使用Runtime的同一Windows用户双击 `runtime-startup-check.bat`，无需管理员权限。
2. 桌面会生成 `Runtime启动检查-日期时间.json`。只把这一个JSON交给管理员，不要发送任何 `.bin`、配置目录或凭据文件。
3. 输出包括管理密钥是否存在/可解密、管理记录基本格式、配对事务状态、文件系统与PowerShell环境布尔检查。解密只在本机内存中完成，输出不含密钥、token、操作内容或原始异常。

工具不启动Host、不运行插件或恢复事务、不修改Runtime配置；只在桌面写检查JSON。可读不等于Node有写权限，系统PowerShell解密成功也不保证客户端调用环境相同；这些限制随摘要说明。配置缺失可以是正常未配对状态，不能单凭它认定代码11根因。
