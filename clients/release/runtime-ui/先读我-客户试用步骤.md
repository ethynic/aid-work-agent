# r9 客户试用步骤

本包 Windows 安装器未签名，仅用于本次自愿试用。无需安装 Node、npm，也无需运行命令行 Runtime。

1. 解压完整 ZIP，打开“安装文件”里的安装器，选择“仅为我安装”，使用原 Windows 用户和原安装目录。
2. 打开 **AID Work Runtime 验收版**，点击“检查连接并给出处理方式”。原连接有效时保留原配对。
3. 若提示原配置或凭据失效，点击“重新配置连接”。在企业网页“本地工具”生成配对码，填写企业服务地址、设备名称、新码；勾选确认框，再点击“确认处理”。设备名称可以沿用。仅填写输入框不会提交。
4. 显示“新设备凭据已保存”后，点击“完成连接配置”。若提示登记重启，先按页面登记，成功后正常重启 Windows；重新打开并继续完成配置，**不要再次生成配对码**。
5. 收到服务器心跳验证成功后，到网页选定新设备；在“第一方插件”选择“插件包”里的 `boss-0.3.5-dev.aidplugin.zip` 安装。登录 BOSS、刷新插件状态；需要执行任务时再点击“启动执行”。

服务地址由管理员提供，例如 `https://agent2.aidingyi.cn`。配对码五分钟有效；普通新码可以建立新设备。“更换此设备”码需要管理员先更新服务器。原任务与资料保留，新编号不会继承或重跑原任务。

页面提示网络或服务器故障时，按显示的步骤修复后重新检查；页面显示凭据已保存时继续完成配置，避免重复配对。不要删配置文件、批量结束 Node 进程或反复卸载。其他错误请对照“安装与旧版迁移说明.html”中的处理表。

右上角 X 关闭窗口后后台继续运行；托盘“退出”才是退出程序。登录自启可在托盘菜单开启或关闭。

本次现场还需要确认：完成连接后正常退出并重开；正常重启 Windows 后托盘是否自动出现、原连接是否保留、显式停止是否保留。内部真实安装与 Windows 重启尚未完成验收，结果由本次自愿试用确认。
