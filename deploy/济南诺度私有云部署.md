## 3. Docker 安装记录（2026-10-21）

### 3.1 sudo 免密配置（已完成）

`ady` 为 wheel 组用户，已配置 NOPASSWD（文件 `/etc/sudoers.d/ady`，440 权限）：

```bash
sudo sh -c 'echo "ady ALL=(ALL) NOPASSWD: ALL" > /etc/sudoers.d/ady && chmod 440 /etc/sudoers.d/ady'
```

### 3.2 安装步骤

默认 dnf 源（alinux3 + epel）**无 docker-ce**，需先添加阿里云 Docker CE 源（按 CentOS 8 路径）：

```bash
sudo sh -c 'cat > /etc/yum.repos.d/docker-ce.repo << "EOF"
[docker-ce-stable]
name=Docker CE Stable - $basearch
baseurl=https://mirrors.aliyun.com/docker-ce/linux/centos/8/$basearch/stable
enabled=1
gpgcheck=1
gpgkey=https://mirrors.aliyun.com/docker-ce/linux/centos/gpg
EOF'
sudo dnf install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin
sudo systemctl enable --now docker
```

附带安装依赖：fuse-overlayfs、fuse3、slirp4netns、libcgroup 等（al8 签名包）。
