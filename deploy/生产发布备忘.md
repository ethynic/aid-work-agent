## 1. file_assets 历史文件名补录脚本（随 8825d880 发布）

**背景**：file_assets 表（commit 8825d880）上线前，文件原始名只存 Redis（24h TTL），过期后磁盘自愈重建退化为存储名 `file_xxx.ext`。新表只覆盖增量，**存量历史文件名需要跑一次补录脚本恢复**。

**脚本**：`scripts/backfill_file_assets.py`（幂等，可重复执行；dry-run 默认，`--execute` 才写库）

**执行步骤**（在生产 API 容器内）：

```bash
# 1. dry-run 核对待补录数量与样例（不写库）
docker exec aid-agent-api python3 scripts/backfill_file_assets.py

# 2. 确认无误后写库
docker exec aid-agent-api python3 scripts/backfill_file_assets.py --execute
```

**数据源与优先级**：
1. 磁盘扫描 `storage/tenants/{tid}/{scene}/`（name=磁盘名，含 path/size/mime）
2. 消息表原始名（chat_messages attachments/images/downloadableFiles + channel_messages attachments），**在磁盘之后写入、优先级最高**；只覆盖"空名/存储名形态"，不冲已有用户可见名

**验证**：

```sql
-- 按来源统计
SELECT source, count(*) FROM file_assets GROUP BY source ORDER BY 2 DESC;
-- 抽查此前报障文件
SELECT file_id, tenant_id, name, size, source FROM file_assets WHERE file_id = 'file_2ef39b21b91f';
```

**执行记录**：

| 环境 | 日期 | 结果 |

| agent2 测试（124.222.3.254） | 2026-10-12 | ✅ 已执行：磁盘 1241 + 消息 769，表共 1457 行；`file_2ef39b21b91f` 已恢复原始名「04_标准客房卫生间_洁具与五金.xlsx」 |
| 生产 243（129.211.65.243） | 2026-10-14 | ✅ 已执行：磁盘 994 + 消息 430 = 1424 行；剩余 994 个为从未在消息中登记的工具生成文件，保持存储名（预期边界） |

## 3. 2026-10-14 发布专项备注

1. **AgentRunner 分进程部署**（首次在生产启动 runner-api / runner-worker），按 [agent-runner-deploy-checklist.md](agent-runner-deploy-checklist.md) 执行；生产 `.env` 追加 5 个 `AGENT_RUNNER_*` 变量（原 .env 备份 `.env.bak_20261014`）
2. **`AGENT_RUNNER_API_URL` 必须用容器名** `http://aid-runner-api:8091`，不能用服务别名 `runner-api`——agent1 仿真环境（aid-runner-api1）接入同一网络 `agent_aid-network` 且共用别名 `runner-api`，用别名会 DNS 轮询命中仿真实例导致间歇性 401 `SERVICE_UNAUTHORIZED`（2026-10-14 实证）。两环境 `.env` 已改用容器名兜底；仓库级根治见 `deploy/docker-compose.agent-runner.sim.yml`（服务名改 `runner-api-sim`/`runner-worker-sim`，防跨环境别名撞名，agent1 下次更新生效）
3. **Web Push VAPID**（agent2 测试环境亦未配置，生产生成专用新密钥）：`.env` 追加 `WEB_PUSH_VAPID_*` 四变量；私钥必须写**单行 base64url** 原始格式（PEM 多行值会让 docker compose 解析 `.env` 失败，2026-10-14 实证）
4. **⚠️ 快更脚本不重建镜像，recreate 会丢失容器层 pip 安装**：本次发布唯一新增依赖 `pywebpush==2.1.2`（含传递依赖 py-vapid/http-ece）装在容器层，下次 `up --force-recreate` 后需重跑：
   `docker exec -u root aid-agent-api pip install --no-cache-dir pywebpush==2.1.2 -i https://mirrors.cloud.tencent.com/pypi/simple`
   下次重建镜像后自动纳入，此条作废
