## 一、交付概述

企业员工智能代理系统已完成私有化部署并上线运行。系统部署于贵方阿里云服务器，与现有业务系统（宝塔面板、MySQL 及 Java 应用）同机共存、资源隔离，未影响原有业务运行。本次交付以数字员工「**销售助手**」为主要使用对象，面向售前场景提供对话式智能服务。

## 二、交付范围

| 类别 | 内容 |
|------|------|
| 平台主体 | 对话服务、任务执行引擎、Web 管理后台与对话界面、数据库、缓存 |
| 数字员工 | 销售助手（详见下节） |
| 运维能力 | 每日自动备份（数据库 / 附件 / 配置，保留 30 天）、开机自启、健康检查与异常自恢复 |
| 安全能力 | HTTPS 加密访问、数据库仅限本机访问、登录防暴力破解、敏感信息加密存储 |

## 三、销售助手主要功能与使用场景

1. **微信客户会话接待**：通过企业微信客服渠道接入微信，与微信侧客户实时会话，自动解答客户问题、介绍产品，并在沟通中促进客户留资，为销售团队沉淀意向客户。
2. **企业知识库问答**：基于企业自建知识库回答客户问题，产品资料、政策口径等由企业管理员维护更新，回答内容有据可依。
3. **报价单自动生成**：依据企业报价单模板，结合客户实际需求（数量、规格等），自动生成报价单 Excel 文件并交付客户，减少人工制单工作。

## 五、使用与费用说明

系统运行涉及以下两项需要贵方自行续费的外部服务，请安排专人关注账户余额：

**1. DeepSeek 开放平台账户（主力大模型）**

系统主力大模型使用 DeepSeek API，由贵方账户充值付费。请关注账户余额，不足时及时充值，避免影响正常对话服务。

**2. 阿里云账户（余额低于 100 元请及时充值）**

以下四项能力均通过贵方阿里云账户计费，请保持账户余额在 100 元以上：

| 能力 | 用途 |
|------|------|
| 通义千问模型 | 备用大模型（主力模型异常时自动切换，保障服务不中断） |
| 向量模型 | 知识库文档解析与语义检索 |
| 智能语音识别（ASR） | 语音消息转文字 |
| 短信服务 | 登录/找回密码验证码下发 |

> 上述费用均为厂商官方计费，平台不加价；系统后台提供用量统计，可随时核对消耗明细。
