# 贵州研学行程规划技能

## 适用场景

- **行程咨询**：用户咨询贵州研学行程安排、景点推荐
- **方案推荐**：用户需要根据人数、天数、预算等条件推荐合适的行程方案
- **行程定制**：用户有特定偏好（如天文、地质、民族文化），需要定制行程
- **行程调整**：用户对已有行程方案提出修改意见，需要重新调整

当用户提到"研学"、"贵州"、"行程"、"旅游方案"、"天眼"、"喀斯特"等关键词时，应触发此技能。

## 工作流程

### 步骤1：确认客户需求参数

收集以下关键参数，信息不足时主动询问：

| 参数 | 说明 | 示例 |
|------|------|------|
| people_count | 参团人数 | 30人 |
| days | 行程天数 | 6天 |
| budget | 人均预算 | 3000元 |
| preferences | 偏好主题（天文/地质/民族/历史等） | 天文+民族文化 |
| start_date | 出发日期 | 2025-07-15 |
| accommodation_level | 住宿标准（经济/舒适/高端） | 舒适 |

### 步骤2：使用 knowledge_base_search 检索匹配的行程方案

根据客户需求参数，构造检索查询：

```
# 检索行程方案
knowledge_base_search(query="贵州研学 六天 行程安排")

# 检索景点信息
knowledge_base_search(query="天眼 门票 价格 讲解")

# 检索课程信息
knowledge_base_search(query="研学课程 天文 地质 民族")
```

### 步骤3：根据天数和偏好匹配行程

基于检索结果，结合客户的天数和偏好，筛选或组合最优行程方案。如无完全匹配的方案，可基于现有方案进行合理调整。

### 步骤4：输出结构化行程表

按照标准格式输出完整行程安排（见下方输出格式）。

## 行程表输出格式

行程方案以表格形式呈现：

```
| 日期 | 时间 | 活动主题 | 活动内容 | 涉及课程 | 备注 |
|------|------|---------|---------|---------|------|
| 第1天 | 上午 | 出发前往贵州 | 乘高铁/飞机抵达贵阳 | - | 含接站 |
| 第1天 | 下午 | 开营仪式 | 破冰活动、研学任务发布 | 团队建设 | - |
| ... | ... | ... | ... | ... | ... |
```

同时需提供行程概要：
- **总天数/晚数**
- **途经城市**
- **核心研学课程**
- **预估人均费用**

知识库中已有的行程方案：

|---------|------|---------|------|

| 定制方案 | 灵活 | 根据需求 | 可根据客户需求组合调整 |

当客户需求与现有方案不完全匹配时，可参考现有方案进行合理拆分或组合。

## 行程规划原则

- **合理安排每日活动量**：避免过度疲劳，每天主要活动不超过3个
- **同区域景点集中安排**：减少不必要的长途奔波，按地理位置规划路线
- **研学课程与景点匹配**：确保每个景点有对应的研学课程内容
- **预留适当的弹性时间**：考虑交通延误、天气变化等因素，留有调整空间
- **餐饮住宿就近原则**：优先选择景区附近或交通便利的住宿点

## 注意事项

- **所有行程内容必须基于知识库检索结果**：景点、课程、活动的描述必须来自知识库
- **不得编造景点、课程或活动**：如知识库中无相关信息，不要自行臆造
- **知识库中缺失的信息要明确标注"需确认"**：例如门票价格、开放时间等未检索到的信息
- **费用估算需说明依据**：所有费用相关数据需标注来源
- **安全提示**：涉及户外活动的行程需包含基本安全注意事项
