# 合同模板投放目录（用户自备，技能不内置任何模板）

本目录**初始为空**。本技能不捆绑任何企业的合同模板或价格数据，是一个
“给任意格式、任意企业填合同”的通用工具。

## 用法
1. 把你自己的真实合同模板（`.docx`，**不含占位符**）放进本目录。
2. 技能在第 1 步会**动态扫描**本目录，自动识别标题、正文摘要与表格表头，
   据此匹配最合适的一套模板并分析需要填哪些字段。
3. 可同时放入多套模板（如公有云 / 私有云 / 定制开发），技能逐个发现、按需选用；
   命中多套或不确定时，会向你确认一次。

## 注意
- 模板就是客户/己方提供的真实 Word 合同原件，**不要**在模板里插入占位符，
  也不要为了适配技能而修改模板版式——技能只做“定位回填”，版式原样保留。
- 价格数据（价格库 / 报价清单）不放在这里，而是在执行第 4 步时通过
  `fill_contract.py --prices <你的价格库.csv>` 传入，或直接把价格写进 `answers.json`。
  价格必须来自你提供的权威报价清单（资料库），技能本身不内置任何价格。
