# 企微会话代理辅助说明

聊天记录是**旁路日志**：由服务器在成功读取/发送结果受理后自动异步保存，
不需要也不会通过本 Skill 保存、查询或回写业务聊天记录。本 Skill 只提供
代理会话中的日报计划建立命令与使用纪律说明。

## 何时使用

- 代理企微单聊/群聊时按本说明使用三个原工具（读取/批量读取/发送）；
- 用户同意建立日报时，用 `setup-daily-report` 建立/扩展日报计划；
- 用户明确拒绝日报：不安排、不反复询问；不影响聊天记录（记录与日报相互独立）。

## 三工具使用要点

- `wecom_read_session`：session 首次可用完整名称，后续用返回的稳定会话标识；
  cursor 原样回传取增量，`has_more=true` 时先继续排空；不要拼改游标。
- 按日期回顾时传 `date=YYYY-MM-DD`（`timezone` 缺省 Asia/Shanghai）：每页默认
  100 条按时间升序；`include_context=true` 首次带该日零点前最近 100 条背景；
  续页只传返回的日期 cursor，日期/时区/背景参数省略即继承原范围。日期读取
  不推进增量 cursor、不产生待回复候选。
- `wecom_message_send`：沿用已授权目标与自动回复范围；unknown 由原任务只读
  对账，禁止重发同一回复；其他独立会话可继续。

## 附件：暂不支持读取内容

当前**暂不支持读取附件内容**（图片/文件原件、缩略图、Base64 均未开通）。
请依据会话中的可读文本与元数据（文件名/类型/大小）回复；确需附件内容时，
请用户用文字补充说明。不要假装已看过图片或文件，也不要因此拒绝继续本次
文本服务。既有附件展开参数属于旧客户端公开协议，本业务不主动使用。

## 日报计划引导（代理会话中）

用户表达日报意愿时，先确认三点再执行命令：**执行时间**（如每天早上 8 点）、
**纳入会话范围**（当前代理的会话，稳定 ws1 标识）、**特殊关注要求**（可选，
如"重点关注退换货"）。用户明确拒绝则不安排、不再追问。

```bash
# 建立或扩展日报计划（同来源自动复用合适计划；一个计划管理多个会话）
python scripts/wecom_conversation_manager.py setup-daily-report \
  --sessions "ws1.xxx|ws1.yyy" \
  --schedule-type daily --cron "0 8 * * *" \
  --timezone Asia/Shanghai \
  --profile <用户所选智能体> \
  --requirements "重点关注退换货"
```

- 会话标识用读取结果返回的稳定 session（ws1. 开头），不要自造；
- 来源设备自动从当前执行上下文固化（无需传 --device）；只在需要覆盖时才传；
- 一个计划只管理同一来源账号与设备的会话；不同来源分别建立；
- 计划沿用用户所选智能体配置与来源设备；日报生成、通知与页面由系统自动
  完成，代理会话不需要（也不能）代为生成或保存日报。

## 纪律

- 不查询、不保存、不统计云端业务聊天记录表；读取一律走三工具；
- 不伪造附件理解、不伪造"已回复/已处理"结论；
- 日报被拒绝或取消不删除任何聊天历史。
