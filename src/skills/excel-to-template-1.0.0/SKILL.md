# 多来源 Excel → 标准模板汇总技能

## 何时使用此技能

**使用本技能用于**：
- 用户上传多个人员增减报表（各家格式不同）+ 一个标准模板，要求统一填写到模板
- 把 Excel/zip 附件里的增减员数据汇总成一张标准表
- 从邮箱按日期拉取增减员报表附件并汇总（邮件入口）

**关键词触发**：
- Excel 汇总 / 多表合并 / 增减表合并 / 多表填模板
- 增员 / 减员 / 增减员 / 社保增减 / 公积金增减 / 人员变动汇总
- 派单人员 / 离职名单汇总 / 标准模板

---

## ⚠️ 严禁事项

**不要自己读 Excel 逐行整理**——脏表结构（分段表头/两行表头/序列日期/脱敏身份证）
已由管线内置处理，自行整理必然出错且浪费大量 token。所有操作必须且只能通过
`skill_execute` 调用本技能的管线脚本：

```
✅ 正确：skill_execute(skill="excel-to-template", command='python scripts/pipeline.py --files ... --template ...')
❌ 错误：用 excel_process 逐个读取文件自己拼数据
```

## 双入口说明

| 入口 | 适用场景 | 命令 |
|------|---------|------|
| 文件入口 | 用户在会话中上传了来源报表 + 模板（.xlsx 或 .zip） | `--files` + `--template` |
| 邮件入口 | 报表在用户绑定邮箱里，用户给日期范围 | `--email-since YYYY-MM-DD` + `--template` |

**模板识别是自动的**（确定性指纹匹配，零 LLM）：不确定哪个文件是模板时省略
`--template`，脚本按表头指纹识别；都不匹配时必须让用户指认并用 `--template` 传入。
**标准模板不期待来自邮件**（邮件只进来源报表），模板由用户会话提供。

## 操作指南（步骤化）

### 第 1 步：确认输入

- 文件入口：确认会话附件里的来源报表（≥1 个 .xlsx/.zip）与模板（可选）
- 邮件入口：向用户确认起始日期（如 2026-08-01），并确认用户已绑定邮箱

### 第 2 步：调用管线（一条命令）

**文件入口**（附件多时可让用户打成一个 zip）：

```bash
python scripts/pipeline.py \
  --files "202608德勤派单增减人员.xlsx" "万宝盛华人员变动通知.xlsx" \
  --template "生成标准模板格式.xlsx" \
  --output-dir .
```

**zip 包入口**（zip 内含全部来源，模板由指纹自动识别时可省略 --template）：

```bash
python scripts/pipeline.py --zip "ExcelAI测试.zip" --output-dir .
```

**邮件入口**（从绑定邮箱拉取 2026-08-01 起的报表附件；模板在会话上传或省略）：

```bash
python scripts/pipeline.py --email-since 2026-08-01 --template "生成标准模板格式.xlsx" --output-dir .
```

### 第 3 步：解析 stdout JSON 结果

```json
{
  "success": true,
  "xlsx": "/path/生成标准模板格式_汇总_20260819-1430.xlsx",
  "report": "/path/生成标准模板格式_校验报告_20260819-1430.md",
  "stats": {"extracted": 14, "written": 14, "manual_review_count": 0, "llm_calls": 9},
  "email": {"emails_seen": 12, "downloaded": 5}
}
```

### 第 4 步：用 cp 交付两个文件

```python
cp(src="<xlsx 路径>", register_download=True)
cp(src="<报告 .md 路径>", register_download=True)
```

### 第 5 步：向用户汇报

- 成功写入条数、来源文件数
- **人工处理清单**（校验不过、修复 2 轮仍失败的行，宁漏勿错）——提示用户人工处理
- **同人多条**提示（同一人在多个来源出现，已全部保留并标注出处）
- 详见校验报告 .md 的摘要/明细/同人多条/计量小节

## 参数说明

| 参数 | 必填 | 说明 |
|------|------|------|
| `--files` | 二选一 | 来源 Excel 文件路径（可多个；.zip 会自动解包） |
| `--zip` | 二选一 | zip 包路径（解包后全部 Excel 作为来源） |
| `--email-since` | 二选一 | 邮件入口起始日期 YYYY-MM-DD（服务器端 SINCE 过滤） |
| `--template` | 可选 | 标准模板 xlsx；省略时按表头指纹自动识别 |
| `--email-folder` | 可选 | 邮件文件夹，默认 INBOX |
| `--email-limit` | 可选 | 邮件入口最多检查邮件数，默认 50 |
| `--output-dir` | 可选 | 输出目录，默认当前目录（skill 工作区） |

## 管线内部机制（调用者只需了解，不需要做）

1. **模板识别（D3）**：表头指纹匹配内置 schema（纯代码零 LLM）
2. **渲染（M1）**：按数字格式渲染（序列日期 46239 → 2026-08-05 等），脏结构原样给 LLM
3. **脱敏（Q3）**：身份证/手机号替换为 [ID_n]/[TEL_n] 占位符，LLM 全程不见真值，回写时代码还原
4. **抽取（M3）**：分块 LLM 抽取 → 确定性校验 → 错误行回喂修复（≤2 轮）→ 仍败进人工清单
5. **同人多条（D12）**：不去重不合并，全部保留并标注出处
6. **填充（D15）**：纯代码克隆模板写入（增员在前减员在后，样式复制），终检行数/表头/残留
7. **邮件判定（D23）**：①扩展名+关键词（增减/社保/公积金/人员/变动/通知/派单）直接下载；
   ②未命中的走一次 LLM 批量判定。UID 水位记录已处理邮件，重复执行不重复下载（D24），
   全程不标已读
8. **计量**：所有 LLM 调用按 token 计费落库（stage=extract/repair/schema/email_judge）

## 错误处理

| 错误情况 | 处理方式 |
|---------|---------|
| 未识别到模板 | 让用户指认哪个是模板，加 `--template` 重试 |
| 多个文件匹配模板 | 让用户指定其一，加 `--template` 重试 |
| .xls 老格式 | 报错提示用户转存为 .xlsx |
| 邮箱未绑定 | 提示用户先在设置中绑定邮箱 |
| 单附件 >25MB | 自动跳过并在结果与报告中标注 |
| 抽取块级失败 | 任务级失败（不输出部分结果），检查文件后重试 |
