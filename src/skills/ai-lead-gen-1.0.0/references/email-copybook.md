# 冷邮件文案手册

第 10 步使用。

## 一、结构骨架

每封 80-150 词，七段式：

```
1. 主题行     A/B 两版，各 35 字符内，具体、有信息量
2. 钩子       1 句，社媒或官网的具体事实
3. 相关性     我们做什么 → 对他为什么有用
4. 证据       1 个可信凭据
5. CTA        低承诺、可回复
6. 签名       真实姓名、职位、公司全称/简称、联系方式（公司名只在这里出现）
7. 合规要素   退订方式、寄件地址（视法规）
```

## 二、主题行规则

### 2.1 分工：公司简称只放签名，不进标题

| 信息 | 放哪里 | 说明 |
|---|---|---|
| 他的具体情境（钩子） | **主题行** | 决定是否被打开 |
| 品类词（我们做什么） | 主题行，有空间才放 | 让他自我筛选相关性 |
| **公司全称 / 简称** | **签名**（可同时用于发件人显示名） | 陌生人眼里等于乱码，白占 1/3 预算 |

**公司简称不进主题行**，三个理由：

1. 主题行唯一的 KPI 是被打开，靠的是"跟我有关"，不是"你是谁"；
2. 35 字符预算里简称常吃掉 10–15 个字符，往往正是把 `your` 挤掉的那一刀；
3. 它和"商务合作机会"同类——只关于你、不关于他，是群发信号。

正确落点：

- **发件人显示名**：`Zeus Wang | ABC Silicone`（0 字符成本，列表页就能看到）
- **签名**：
  ```
  Zeus Wang
  Sales Manager | ABC Silicone Co., Ltd. (ABC)
  +86 ... | abc-silicone.com
  ```
- 合规要求的可识别性由**签名与寄件地址**承担，不是主题行。

**唯一例外**（都不是"为了介绍自己"）：品牌在该细分行业已有认知度；转介绍（此时写介绍人更有用）；同一线程的跟进；展会/名片后首次联系。

### 2.2 好与坏的对照

**好**（具体、有钩子）：
- `快速提问 —— 贵司 X 产线的良率问题`
- `关于贵司 Y 产品目录中提到的 Z`
- `你写的关于 Y 的文章 —— 一个想法`
- `X 品牌在 Y 国的分销机会`

**坏**（空泛、触发垃圾过滤）：
- `商务合作机会`
- `我们是专业的XX制造商`
- `ABC Silicone — 商务合作` ← **公司简称塞进标题，既占字符又像群发**
- `RE: Re: Fwd: Fwd:` ← **绝对禁止，这是垃圾邮件典型特征**
- 全大写 + 多个感叹号
- 含 `FREE`、`URGENT`、`100%`、`ACT NOW`

### 2.3 本地化示例

| 语言 | 主题行示例 |
|---|---|
| 德语 | `Kurze Frage zur Lieferkette in Ihrem Werk` |
| 法语 | `Question rapide — votre gamme de produits` |
| 西班牙语 | `Consulta sobre su línea de producción` |
| 日语 | `貴社の生産ラインについて一つ提案` |
| 中文 | `关于贵司华东区渠道合作的一个想法` |

### 2.4 A/B 两版（每封信必写两版）

每封邮件写 `Subject A` / `Subject B` 两版，按 `ab_group` 分流给不同收件人。

**写两版的规则**

1. **一次只测一个变量**。推荐组合：
   - A = 纯钩子 / B = 钩子 + 品类词
   - A = 痛点型 / B = 观点型
   - A = 提问句 / B = 陈述句
2. 两版都必须是**能独立成立的稿子**，不能一版是明显废稿，否则测出来的只是"好稿 vs 烂稿"。
3. 两版**都 ≤35 字符**，都不得含 `Re:`/`Fwd:`、全大写、感叹号、触发词。
4. 两版**都不得写公司简称**（见 2.1），简称统一放签名。
5. **长度尽量对齐**，差距 ≤8 字符，否则"长度"会变成第二个变量。

**分组规则**

- 在**写草稿时**就交替分配 `ab_group`（A/B 各半），写进 `emails/*.md` 与 `emails.json`；
- **不要在发送时随机**：分组是计划的一部分，要可复查、可中断续跑；
- 未填 `ab_group` 时，`send_emails.py` 按收件人地址哈希稳定分流（同一人跨次运行结果一致）。

**落盘格式**（`emails/<company>-<person>.md`）

```
To: Hans Muller <h.muller@example.de>
Subject A: Kurze Frage zu Ihrer Lieferkette
Subject B: Dichtungen fuer Ihre Produktionslinie
AB group: A
Body: ...
依据: 官网 2025 年新增产线 / 招聘 JD 提到良率
```

**判读规则（别过度解读）**

- 主题行影响的是**打开率**；打开率需要 `track_opens: true` 才有数据。未开追踪时只能用**回复率**做代理指标，噪声更大。
- 样本 <100 封时，两版差异基本是噪声，别据此定论——把它当"两条并行文案"而非科学实验。
- 例：A 组 50 封 3 回复、B 组 50 封 1 回复，仍不足以判断。继续累积，或回到钩子质量本身。
- 汇总时按 `logs/send_log.csv` 的 `ab_group` 列分组统计，别凭印象。

## 三、钩子来源（按可信度排序）

| 来源 | 例句 | 可信度 |
|---|---|---|
| 联系人自己发的文章/观点 | `读到您去年关于 Y 的文章，提到 Z 的困扰` | 最高 |
| 官网近期动态 | `注意到贵司今年在 X 开设了新工厂` | 高 |
| 招聘 JD 暴露的痛点 | `看到贵司在招聘 Y 岗位，我们正在做相关的事` | 高 |
| 公司新闻稿/融资 | `恭喜贵司完成 X 轮融资` | 中 |
| 官网产品目录 | `贵司官网列出的 X 产品，我们有配套方案` | 中 |
| 无钩子 | 直接从相关性切入 | 兜底 |

**禁止的钩子**：
- 编造的合作关系（"我们一直关注贵司" → 空话）
- 假装看过但实际没看的内容
- 过度私密的个人信息
- 明显的模板痕迹（"I hope this email finds you well"）

## 四、四种模板变体

### 变体 A：痛点型（最通用）
```
Subject A: [具体痛点相关]
Subject B: [痛点相关] — [品类词]

Hi [First name],

[钩子 — 1 句具体事实]

We make [产品一句话]. For [他的细分场景/品类], this usually 
helps with [具体收益].

[证据 — 1 句：客户案例/认证/数据]

Would it be useful if I sent over [具体低价承诺的动作]?

Best regards,
[Name]
[Title], [Company full name]
[Contact]

---
To stop receiving these emails, reply "unsubscribe" or 
click [退订链接]. We're at [公司地址].
```

### 变体 B：内容/观点型（用于社媒有发声的联系人）
```
Subject A: 关于您写的 Y
Subject B: 您文中 Z 的一个想法

Hi [First name],

您去年那篇关于 [话题] 的文章我读了，特别是关于 [具体观点] 那段。

我们做的 [产品] 正好和这个问题相关 —— [1 句关联]。

[证据]

想听听您怎么看？20 分钟电话或直接回这封邮件都行。

Best,
[签名]

---
退订说明
```

### 变体 C：合作/分销型（找经销商）
```
Subject A: [产品] 在 [国家] 的分销机会
Subject B: [国家] 市场的 [产品] 供应

Dear [Name],

我们制造 [产品]，目前主要供应 [市场]。正在寻找 [国家] 
地区的合作伙伴。

贵司的 [具体业务特点] 与我们的产品线匹配度很高。

[证据：产能/认证/现有客户市场]

是否可以在下周的 [具体时段] 打一个 15 分钟的电话？

Best regards,
[签名]

---
退订说明
```

### 变体 D：换机型/替代供应型（面向采购）
```
Subject A: 关于贵司 [产品线] 的一个供应建议
Subject B: [产品线] 的替代供应方案

Dear [Name],

注意到贵司 [官网具体产品/业务]。

我们生产 [产品]，规格 [具体规格]，目前 [MOQ/交期/认证优势]。

如果有兴趣，我可以先寄样品或提供报价单。

Best regards,
[签名]

---
退订说明
```

## 五、语言本地化要求

**不要直译**。用目标市场的商务惯用表达：

| 直译（错） | 本地化（对） |
|---|---|
| `Dear Mr. Smith, I hope this email finds you well.` | 德语：`Guten Tag Herr Müller,` 直接切入 / 日本：`○○株式会社 ○○部 御中 様` |
| `I want to introduce our products.` | 德语：`Ich möchte Ihnen kurz unser Produkt vorstellen` / 法语：`Je me permets de vous présenter` |
| `Please give me your favorable reply.` | 日语：`ご一報 Uniteautoappreciated` → 正确：`ご検討いただけると幸いです` |
| `Our company is a leading manufacturer.` | 直接删掉。用证据代替自我评价。 |

**本地称呼**：
- 德语：`Herr/Frau [姓]`，正式邮件用 `Sehr geehrte Frau [姓],`
- 法语：`Madame/Monsieur [姓]`，用 `vous`
- 日语：`[姓] [名] 様` + `いつもお世話になっております`
- 韩语：`[姓] [名]님` / `안녕하세요`
- 西班牙语：`Estimado/a Sr/a [姓],`
- 中文：`[姓] [名] 您好`

### 称呼按收件人类型定，不要按心情定

| 收件人类型 | 称呼 | 说明 |
|---|---|---|
| 个人企业邮箱 + 官网核验过姓名对应 | 姓 + 敬称（`Herr Müller` / `张经理`） | 唯一可以写具体人名的情况 |
| 个人企业邮箱但未核验 | **"您好："** | 形似人名不等于这个人，先核验再写称呼 |
| 对口部门邮箱（`purchasing@`） | **"您好："** 或"尊敬的采购部" | 部门邮箱不知道具体是谁 |
| 公开窗口（`info@`） | **"您好："** | ⚠️ 本技能不再向公开窗口发送 |

**写错称呼比写得笼统伤害更大** —— 叫错名字比叫"您好"更显得像群发。

## 六、个 性 化要求（硬性）

每封邮件必须包含**至少 2 处**只对该公司成立的细节：
1. 钩子（他的具体事实）
2. 用**他官网的品类词/产品名/地名**（不是我们的通用词）

反例（所有人收到都一样）：
> "我们是中国领先的 XX 制造商，拥有 20 年经验，服务全球 500+ 客户。"

正例：
> "您目录里的 [具体产品名] 系列目前主要从亚洲进口——我们做过同规格的 [认证]，2025 年给 [同类客户] 做过类似替换。"

## 七、发送前自查清单

逐条核对，任何一条不过就不发：

- [ ] 主题行写了 A/B 两版，各 ≤35 字符，无 Re:/Fwd:，无全大写感叹号
- [ ] 两版只差一个变量，长度差距 ≤8 字符
- [ ] 两版都不含公司简称（简称只在签名与发件人显示名里）
- [ ] `ab_group` 已分配，A/B 大致各半
- [ ] 收件人姓名与公司对得上（检查拼写、称谓）
- [ ] 至少 2 处个性化细节
- [ ] 正文 80-150 词
- [ ] 无拼写错误（用工具检查，尤其非母语邮件）
- [ ] 签名含真实姓名、职位、公司全称/简称、联系方式
- [ ] CTA 低承诺且可回复（不是"请立即购买"）
- [ ] 含合规要素（退订方式、寄件地址，视法规）
- [ ] 无敏感信息、不涉及对方隐私
- [ ] `email_source` 与 `confidence` 达标（low 置信度不发送）
