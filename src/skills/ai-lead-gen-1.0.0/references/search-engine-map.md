## 关键语法提示

- `site:` 在 Google / Bing / Yandex / Naver(用 `site:` 不生效，改用网址直接搜) 支持良好；百度 `site:` 支持有限，优先换关键词组合
- Google 不支持 `intitle:` 之外的复杂嵌套；Bing 支持 `filetype:pdf` 找公司文档与产品手册
- DuckDuckGo 的 `!g` 前缀可在单次搜索中切到 Google 结果
- 找 PDF 版名录/手册：`filetype:pdf "<行业>" "catalog" "<国家>"`
- 排除黄页噪音：`-site:yellowpages.com -site:yelp.com -site:facebook.com`

## 行业名录按类型选

| 类型 | 作用 | 典型站点 |
|---|---|---|
| 行业协会名录 | 权威、质量高、客户明确在该行业 | 各国行业协会官网 member directory |
| 展会参展商名录 | 有采购力、近期活跃、公开联系方式 | 官网 Exhibitor List，多数支持按行业/国家筛选 |
| B2B 平台 | 中小供应商多，可批量挖联系方式 | Alibaba、Global Sources、Hobi、Kompass、Europages、ThomasNet |
| 企业注册库 | 验证公司真实性与规模 | 各国商会/统计局企业登记（Companies House、North Data、企查查） |
| 综合黄页 | 本地中小企业 | Google Maps、本地黄页站 |
| 电商/零售平台 | 判断公司是否自营、规模 | Amazon 品牌页、当地电商（Shopee、Lazada、Coupang） |
| 招聘站 | **常暴露痛点**（他们在招什么岗位=在做什么事） | LinkedIn Jobs、Indeed、StepStone、Bayt |
| 新闻/融资数据库 | 判断公司活跃度与规模 | Crunchbase、企查查、Companies House、新闻稿站 |
| 企业社媒 | 查员工与公司动态 | LinkedIn、Facebook Page、X |
