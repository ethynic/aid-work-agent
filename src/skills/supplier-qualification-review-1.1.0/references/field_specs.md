# 字段规范与编码规则（供应商资质审查参考）

本文件供 `supplier-qualification-review` 技能在真实性审查阶段使用，提供营业执照字段规范、
统一社会信用代码（USCC）编码规则，以及常见资质文件的判断要点。均为本地静态知识，**不涉及任何联网/搜索**。

---

## 一、营业执照核心字段（抽取目标）

| 字段 | 说明 / 判断要点 |
|---|---|
| 公司名称（全称） | 须与印章、正文、各资质文件持证单位完全一致 |
| 统一社会信用代码 | 18 位，见下方编码规则；须通过 `scripts/verify_uscc.py` 校验 |
| 类型 | 有限责任公司 / 股份有限公司 / 一人有限责任公司 / 个体工商户 / 合伙企业 等 |
| 法定代表人 | 姓名 |
| 注册资本 | 金额 + 币种（注意「万元」与「元」单位）；认缴 vs 实缴 |
| 成立日期 | YYYY-MM-DD |
| 营业期限 | 起止日期；或「长期」 |
| 经营范围 | 文本；关注是否包含本次采购所需的经营类目 |
| 住所 / 注册地址 | 文本；可与实际经营地不同 |
| 登记机关 | 市/区市场监督管理局等 |
| 发证日期 | YYYY-MM-DD；一般晚于成立日期 |

> 营业执照为「多证合一」后版本，右上角有二维码，统一社会信用代码取代原注册号/组织机构代码。

## 二、统一社会信用代码（USCC）编码规则（GB 32100-2015）

- **结构**：18 位 = 登记管理部门代码(1) + 机构类别代码(1) + 登记机关行政区划码(6) + 主体标识码/组织机构代码(9) + 校验码(1)。
- **字符集**（31 个，不含 I O S V Z）：`0123456789ABCDEFGHJKLMNPQRTUWXY`。
- **校验算法**：ISO 7064 MOD 11-3。
  1. 取前 17 位，每位字符在字符集中的序号 × 对应权重 `[1,3,9,27,19,26,16,17,20,29,25,13,8,24,10,30,28]`；
  2. 求和后对 31 取模，得 `mod`；
  3. 校验值 `c = 31 - mod`；若 `c == 31` 则取 `0`；
  4. 第 18 位 = 字符集中第 `c` 个字符。
- **登记管理部门代码（第 1 位）常见取值**：`9`=市场监管(工商)、`1`=机构编制、`2`=民政、`3`=司法行政、`4`=农业、`5`=宗教、`6`=教育、`8`=卫生、`A`=证监会、`B`=保监会、`F`=海关、`G`=税务 等。
- **机构类别代码（第 2 位）常见取值**：`1`=企业、`2`=个体工商户、`3`=农民专业合作社、`4`/其他=其他组织机构。

> 校验失败时（长度错、含非法字符、校验位不符、登记部门未知），应直接标记为「代码非法 / 疑似伪造」，并要求人工复核。

## 三、常见资质文件清单与有效期判断要点

| 资质类别 | 典型证书 | 有效期判断要点 |
|---|---|---|
| 建筑 / 工程 | 建筑业企业资质证书、安全生产许可证（安许证） | 资质分等级（特级/一级/二级/三级）；安许证一般为 3 年，到期需延续 |
| 生产许可 | 工业产品生产许可证、全国工业产品生产许可证 | 注明有效期，过期失效 |
| 体系认证 | ISO 9001 / 14001 / 45001 认证证书 | 通常 3 年，含年检/监督审核；注意是否暂停/撤销 |
| 特种行业 | 食品经营许可证、医疗器械经营/生产许可证、危化品经营许可 | 强时效，过期即无资质 |
| 强制性产品 | CCC 认证证书 | 登录官方可查；注意证书状态 |
| 荣誉 / 资信 | 守合同重信用、AAA 信用等级 | 注意发证机构权威性、有效期 |

**判断要点**：
- 任何资质证书都应有明确的「有效期起止」与「发证机关」；缺失 → 标记为存疑。
- 比对当前日期（`date +%F`）判断是否过期；过期 → 该资质视为无效。
- 证书等级/类别须与供应商自述的经营范围、投标要求相匹配。
- 编号明显不合该类证书常规格式（位数、前缀）时 → 标记格式异常，提示人工/官方核验。

## 四、伪造 / 异常痕迹速查（视觉判断）

- 图像模糊、关键信息（代码、日期、金额）被遮挡或无法辨认。
- 印章缺角、模糊、位置/颜色异常，或多枚印章重叠不协调。
- 字体、字号、排版与同版式官方样本不一致；水印异常。
- 拼接/PS 痕迹：边缘不自然、色彩断层、文字与背景融合异常。
- 信息自相矛盾：如注册资本极小却声称大型工程业绩；成立时间晚于发证日期；营业期限起始早于成立日期。
- 二维码/防伪标识缺失或异常（可提示用户扫码核验证照，但**扫码核验属外部动作，由上级智能体或用户完成**）。
