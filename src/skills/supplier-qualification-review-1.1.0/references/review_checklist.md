# 审查清单与外部核查委托单填报表

本文件是 `supplier-qualification-review` 技能的可勾选清单与填报表样例。
- **真实性审查（A 组）** 由技能本地完成，无需联网。
- **信用/风险审查（C 组）** 需要外部数据，由**执行本技能的上级智能体**使用其自带检索能力
  （`web_search` / `web_fetch` 工具）检索后回填；技能只消费返回数据。

---

## A. 真实性审查清单（本地，可勾选）

- [ ] A1 资料归集：营业执照、公司名称、资质文件已编号归档
- [ ] A2 字段抽取：营业执照关键字段已用视觉读取并填入报告
- [ ] A3 USCC 校验：`verify_uscc.py` 已运行，结果已记录
- [ ] A4 公司名称一致性：营业执照 / 用户提供 / 资质文件 三者一致
- [ ] A5 资质有效期：每份资质均在有效期内（已比对当前日期）
- [ ] A6 编号格式：资质证书编号符合常规规则
- [ ] A7 伪造痕迹：无模糊/遮挡/印章异常/PS/信息矛盾
- [ ] A8 真实性结论：✅真实 / ⚠️存疑 / ❌疑似伪造

**真实性结论判定**：
- 全部 ✅ → 真实
- A4/A5/A6/A7 任一 ⚠️ → 存疑（需补充材料或人工复核）
- A3 不通过 或 A7 发现明确伪造痕迹 → 疑似伪造

---

## C. 外部核查委托单（由上级智能体检索回填）

> 上级智能体对「公司名称 + 统一社会信用代码」执行检索，将每条的「检索发现 / 来源 / 风险信号」
> 回填下表。技能依据回填结果做风险定级（见 SKILL.md 阶段三）。

| 编号 | 核查项 | 建议检索关键词 | 检索发现 | 来源 | 风险信号 |
|---|---|---|---|---|---|
| C1 | 工商登记一致性 | `"<公司全称>" 统一社会信用代码 "<USCC>"` | | | |
| C2 | 失信被执行人 | `"<公司全称>" 失信被执行人 限制高消费` | | | |
| C3 | 裁判文书/司法风险 | `"<公司全称>" 裁判文书 开庭公告 被执行人` | | | |
| C4 | 行政处罚 | `"<公司全称>" 行政处罚 市场监管` | | | |
| C5 | 经营异常/严重违法 | `"<公司全称>" 经营异常名录 列入经营异常` | | | |
| C6 | 股权冻结/出质/变更 | `"<公司全称>" 股权冻结 股权出质 工商变更` | | | |
| C7 | 行业/舆情风险 | `"<公司全称>" 投诉 曝光 安全事故 质量` | | | |
| C8 | （可选）资质公开核验 | `"<资质名称>" "<证书编号>"` | | | |

**回填样例**：

| 编号 | 核查项 | 检索发现 | 来源 | 风险信号 |
|---|---|---|---|---|
| C1 | 工商一致性 | 公开工商信息显示统一社会信用代码与提交一致，存续状态正常 | 国家企业信用信息公示系统检索结果 | 无 |
| C2 | 失信/限高 | 检索到 1 条失信被执行记录，标的额 80 万元 | 某法院公告 / 公开执行信息 | 🔴 命中 |
| C3 | 司法风险 | 近 3 年作为被告民事案件 2 起，已结案 | 裁判文书网检索 | 🟡 一般 |
| C4 | 行政处罚 | 未检索到 | — | 无 |
| C5 | 经营异常 | 2024 年曾列入经营异常（地址失联），已移出 | 公示系统 | 🟡 历史 |
| C6 | 股权冻结 | 未检索到 | — | 无 |
| C7 | 舆情 | 未检索到重大负面 | — | 无 |

→ 综合：C2 命中失信 → **🔴 高风险**，准入建议：❌ 否决。

---

## 风险等级速查

| 等级 | 条件 |
|---|---|
| 🔴 高风险 | C2 失信/限高；或 C3 重大被执行/大额诉讼；或 C5 严重违法失信；或 A8 疑似伪造 |
| 🟡 中风险 | C3/C4/C5/C6/C7 任一存在一般风险记录（零星诉讼、单笔处罚、异常已移出、冻结线索） |
| 🟢 低风险 | C1–C8 均无公开风险记录，且 A8 = 真实 |
