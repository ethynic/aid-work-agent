# 售前咨询外部系统 API 配置

## 如何使用此技能

当需要把售前留资推送到外部客户管理系统（创建客户、创建跟进记录等）时：

1. 先执行以下命令加载当前租户的 API 配置：

```bash
python scripts/load_api_config.py
```

2. 脚本会返回当前租户配置的外部系统 API 说明文本（Markdown 格式）
3. 仔细阅读返回的 API 说明，了解：
   - 外部系统的 Base URL 和认证方式（如双 Token 委托登录）
   - 可用的 API 端点、请求格式、字段映射和响应格式
   - 客户信息 / 跟进记录的字段要求（哪些必填、哪些选填、字段英文名）
4. 根据说明使用 http_api 工具调用外部系统
5. URL 和 headers 中的 ${VAR_NAME} 环境变量会自动替换为实际值

## 留资推送流程建议

每次留资成功后，按以下流程把客户信息推送到外部系统：

1. 若文档要求委托登录（双 Token），先调用登录接口获取 `client_token`。**登录的 mobile 参数取 `record_lead_capture` 成功结果中的 `assignee_phone`（归属员工手机号），切勿使用客户手机号或留空**；会话内后续业务接口均携带双 Token
2. 按文档调用客户信息创建接口，把本会话收集到的客户姓名、手机号、微信号、需求摘要等映射到文档字段
3. 如文档要求，再创建跟进记录沉淀本次咨询内容
4. 会话结束前按文档调用登出接口使 `client_token` 失效

## 注意事项

- 每次对话中首次需要调用外部 API 时，都要先执行脚本获取最新配置
- 字段映射以当前返回的 API 说明文档为准————不同租户、不同外部系统的字段各不相同，切勿凭记忆硬编码字段名或应用编号
- 手机号等敏感信息仅用于接口参数，不向用户透露其他客户的信息
- 写操作（创建客户、创建跟进记录等）前，先向用户确认信息再调用
- 如果脚本返回"未配置"，说明该租户尚未配置外部系统，仅使用 record_lead_capture 工具完成本地留资记录即可，无需推送
- 每个接口的响应先检查 `Code` 字段：`Code=0` 才表示成功
- `Code != 0` 为业务错误（如 `{"Code": -1, "Error": "非空内容"}`），对照文档修正参数后重试；`assignee_phone` 为空或重试仍失败则降级为仅本地留资
- 外部系统推送失败时降级为仅本地留资，不阻塞与用户的正常对话
