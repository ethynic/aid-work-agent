# 产品效果图（interior-render）

把「户型图 + 产品/材质图」变成**真实感强、产品颜色质感还原到位**的室内效果图。
结构判读用 `image_read`（多模态读图），取色用 `scripts/sample_color.py`（经 skill_execute），
出图用 `image_render`（无参考图=文生图，1-3 张参考图=图生图）。

## 何时用
- 用户给出户型图（或某房间）+ 产品/材质照片，要"出效果图 / 看产品摆进去 / 铺上这款砖什么样"。
- 关键词：户型图、效果图、产品进家/进店预览、地砖墙砖/岩板/家具/灯具 上墙效果。
- 不适用：需要**度量级精确尺寸/坐标**的 2D 布局（那是几何任务，扩散模型不保证）。

## 核心思路（两层，但轻量）
1. **结构真值靠"读图"，不靠出图模型**：墙体/门窗/空间数量由 `image_read` 在**原始清晰户型图**上判读。出图模型只负责把选定空间渲染真实，**换模型不会修复结构识别错误**。
2. **产品还原靠"参考图 + 精确色"，不靠文字描述**：把**真实产品图**作为 `image_render` 的参考图（材质锚点），并在提示词里锁定颜色（精确 HEX），禁止用"暖白/米色"等模糊词让模型自由发挥。

## 关键纪律（踩过的坑，必须遵守）
- **禁止用像素阈值 / 骨架化 / Canny 自动提取来"生成结构"**。曾为做"纯净蓝图"对户型图跑阈值，把较浅/较细内墙一起滤没，产出"看似全开放、实际丢光内墙"的失真图，导致房间数与墙体全错。结构只能由 `image_read` 在原始图上判读。
- **清晰度闸门**：若户型图分辨率过低、线条发虚、或同一交界连通性反复判读不一致 → **不要糊图上下结论**，请用户提供更高清的户型图后再做。
- **喂原始带家具户型图时**，提示词必须显式声明"家具/地毯/虚线/圆弧**不是墙**，不得当成隔断或凭空加墙/吧台/柱"，否则模型会把家具线读成隔断、房型错位。
- **出图模型的 edit 只接受 1-3 张参考图**。若需同时锚定 >3 张（多产品/多角度），分批生成（每次 ≤3 张）。
- **右下角"AI生成"角标为会话界面显示标识（前端渲染，租户可在管理后台开关）**，生成图片文件本身无水印；不要靠提示词去水印，也不要向客户宣称"图片带水印去不掉"。
- **3D 是视觉近似**：交付时如实说明"尺寸/朝向以户型图为准"；不保证度量精确。
- **锁房间比例/结构只能靠"整图喂 + 以图生图"，不能靠纯文字、也不能裁剪单房间**：要还原某房间的真实长宽比，必须把**整张户型图 + 产品图一起**喂给 `image_render`，并在提示词命令模型"严格按户型图中该房间那块的真实尺寸比例生成"。**禁止**用纯文字描述去锁比例（不可能精确），**禁止**把单个房间从户型图上裁剪出来再喂（视觉定位不可靠、且丢失上下文）。若模型把采光墙旋到侧墙 / 在侧墙违规开大窗：改用**竖构图**（强制沿进深拉开纵深）+ 把"镜头站在 X 端朝 Y 拍、尽头=主采光面、左右两侧=实墙绝不许开窗"写成最高优先级硬约束。
- **取景角度按空间类型走默认最佳机位**（用户不指定即用默认，指定则从之），详见 Phase 2.5。切忌正对尽头墙的扁平"走廊式"正面机位。

## 工作流

### Phase 0 · 澄清（只在有歧义时问，能合理默认就直接做）
- **目标空间由产品品类决定，不是一律取最大厅**：
  - 地面材质（地砖/地板/岩板地铺）→ 该住宅或商铺中最该展示的主空间（客餐厅、店铺大厅…按品类）。
  - 墙面材质（墙砖/岩板上墙/涂料/壁纸）→ 产品图或用户暗示的那面墙所属空间。
  - 单体产品（家具/洁具/灯具）→ **其所属房间**：沙发/茶几→客厅，床/衣柜→卧室，马桶/浴室柜→卫生间，餐桌/吊灯→餐厅，陈列/射灯→店铺。
  - 用户点名空间则一律以用户为准，并说明所做的假设。
- 产品：单图多件时确认哪一件/哪种材质进图；产品品类已隐含摆放面（地砖→地面、壁灯→墙面）则不必再问。
- **场景类型也要判**：户型图/产品图暗示是商铺（零售店、 showroom）还是住宅，据此切换模板里的 `<住宅/商铺>`。

### Phase 1 · 读素材（`image_read`）
**固定只读 2 次**：户型图一次 + 产品图一次（每次一张图，question 要求结构化输出）。**禁止重复判读、复核或换问法再读**（仅清晰度闸门触发时例外）。产出：
- 户型：深色/加粗墙围合的真实房间数与方位、目标空间形状、门窗位置、**有无尺寸标注/比例尺**、图上是否已印房间名。触发清晰度闸门。
- 产品：品类+类型、**精确颜色（色名+明度/冷暖倾向）**、纹理、光泽（哑光/亮面）、规格、是否成组、需裁掉的无关背景。

`image_read` 返回 `answer`（判读结论）+ `file_path`（图片本地绝对路径，Phase 2 取色要用）。

### Phase 2 · 锁定精确色/材质（推荐，专治"色差"）
从产品图的**纯净区域**取色写进提示词，不要用"暖白/米色"等模糊词让模型自由发挥：

```bash
python3 scripts/sample_color.py --image "<产品图本地路径或URL>" --crop x,y,w,h [--out swatches.json]
```

经 `skill_execute` 执行本技能脚本。**图片输入必须是本地绝对路径或 URL**：用 Phase 1 中 `image_read` 返回的 `file_path`；file_id（file_xxx）不能直接喂脚本。省略 `--crop` 取中心 40%；尽量框住"纯净材质样块"，避开家具/人/招牌/灯箱/结构面/接缝高光。

- **表面材质类**：地面/墙面各取一块 → `floor=#xxxxxx, wall=#yyyyyy`；若源图墙地同色就统一一个 HEX。
- **单体产品类**：取产品主体色块 → `<品类>=#xxxxxx`，同时记下材质（布艺/皮革/金属/木质/玻璃等）与光泽。

**只描述源图里真实存在的颜色与材质**，不得自行加灰墙/水泥/石纹/亮面等源图没有的东西。

### Phase 2.5 · 取景角度（按空间类型取默认最佳机位）
**通则**：避免正对尽头墙的扁平"走廊式"正面；默认用**对角斜视 / 斜侧三分之四视角**——相机置于靠近一侧墙角、朝对角方向拍，同时纳入主采光面与一面侧墙，既显纵深又显宽度、更立体。**用户指定机位则一律以用户为准**；未指定按下表默认：

| 空间类型 | 默认机位 | 构图 |
|---|---|---|
| 客厅 / 起居室 | 站在与主采光面（阳台/大窗）相对那端的**某侧墙角**，朝对角看向采光面，斜侧约 **30-45°**，纳入采光面 + 一面侧墙（电视墙或沙发墙） | 横为主（狭长厅可适度竖，但仍斜侧、不做纯正面） |
| 主卧 | 门口对角，以**床头背景墙**为视觉主体，约 **30-40°** 斜视，纳入窗/飘窗 | 横 |
| 餐厅 | 以**餐桌**为主体，约 **45°** 三分之四斜视，纳入相邻客厅或窗 | 横 |
| 厨房 | L 形/一字**沿长轴**从开口端朝灶台墙，约 **30-40°** | 横 |
| 卫生间 | 门口对角约 **45°**，纳入洗手台 + 淋浴/浴缸 | 横 |
| 小空间（次卧/卫/厨） | 略广角、机位抬高、尽量**对角拉长**显宽敞 | 视情况 |

把选定的机位写进 Phase 3 模板的"取景"句；负向词固定加入 `正对尽头墙, 走廊式正面, 扁平视角, 侧墙开窗, 左右墙落地窗`。

### Phase 3 · 生成（`image_render`，图生图）
参考图顺序：**`[产品图(材质锚点), 户型图(布局锚点)]`**（顺序即语义顺序）。调用：

```
image_render(
  prompt="<见下方模板，<…> 用 Phase 0/1/2 判读结果填入>",
  negative_prompt="<见下方模板>",
  reference_images=["<产品图>", "<户型图>"],
  size="1280*960", n=1
)
```

参考图支持本地绝对路径（含 `image_read` 返回的 `file_path`）/ file_id / URL。**户型图必须整张一起喂**（它是布局/比例锚点）。若加户型图后模型把家具读成墙、或房型/比例乱 → **不要删户型图**，而是①在提示词重申"家具/地毯/虚线/圆弧不是墙、不凭空加隔断"，②把该房间的真实长宽比写成硬约束，③按 Phase 2.5 选对角斜视机位、必要时改竖构图。只有在反复确认结构仍不可控时，才退化为"仅产品图 edit + 文字描述空间"，且须向用户说明比例不再锚定户型图。

n=1（按张计费，客户明确要多方案对比时才调大）；同一 seed+prompt 可复现，调优对比时指定 seed。

**按产品类别选模板（关键：不同品类"还原重点"不同，切勿一律用铺贴话术）：**

**A. 表面材质类**（地砖/墙砖/岩板/石材/瓷砖/涂料/壁纸——还原"铺开后的颜色与质感"）：
```
生成一张<住宅/商铺><目标空间>的写实室内效果图。空间几何以第二张户型图中<Phase1 判读的方位>那块<形状>区域为准，
严格按户型图中它的真实尺寸与长宽比例生成（如<南北向长方形、进深>面宽>），不要做成正方形或横向厅；
<哪面墙>为采光窗，其余为内墙；不要把户型图里的家具、地毯、虚线、圆弧当成墙或隔断，不要凭空增加隔墙/吧台/柱子。
【取景】<Phase 2.5 选定机位，如：相机站在与采光面相对那端的某侧墙角、朝对角斜看向采光面，约35-45°三分之四视角，
同时纳入尽头采光面与一面侧墙，不要正对尽头墙拍成扁平走廊式正面；采光面以外的侧墙必须是实墙、禁止开大窗>。
材质严格以第一张产品图为准：<地面/墙面>铺贴与产品图完全相同的<品类>——颜色 <Phase2 精确 HEX，如 floor=#xxxxxx>，
<哑光/亮面>表面，<按产品图的砖缝规格/纹理方向/是否通铺>。要求：颜色忠实还原产品图，不要偏冷/偏蓝/偏灰/过度增白；
真实<哑光>质感，表面均匀干净，绝对不要白色涂抹斑块、不规则镜面高光、水渍或噪点；墙·顶·地交界过渡自然，
不要水平色差分界线。<现代简约软装协调…>，自然窗光，专业室内实景摄影质感，高细节，透视正确。
画面干净，不要任何文字、水印、角标、品牌字样或 logo。
```
负向词 A：
```
正对尽头墙, 走廊式正面, 扁平视角, 侧墙开窗, 左右墙落地窗, 正方形空间, 比例与户型图不符,
偏蓝, 偏冷色, 过度增白, 白色涂抹斑块, 镜面反光斑块, 水渍, 噪点, 水平色差带,
把家具当地墙, 多余隔墙, 吧台, 品牌文字, 水印, logo, 卡通, 塑料感
```

**B. 单体产品类**（沙发/床/餐桌椅/柜/灯具/洁具/陈列道具——还原"这一件产品的造型·比例·颜色·材质"）：
```
生成一张<住宅/商铺><目标空间>的写实室内效果图。空间几何以第二张户型图中<方位>那块<形状>为准，
严格按户型图中它的真实尺寸与长宽比例生成，不要做成正方形或比例失真；<采光窗方位>；
不要把家具线当墙，不要凭空加隔断。【取景】<Phase 2.5 选定机位，如：以床头背景墙/餐桌/产品主体为视觉焦点的
约35-45°对角斜视三分之四视角，纳入窗/采光面与一面侧墙，不要正对尽头墙的扁平正面；非采光侧墙为实墙不开大窗>。
画面主体摆放与第一张产品图完全相同的<品类>——保持其<造型/轮廓/靠背/腿脚等结构>、
颜色 <Phase2 精确 HEX>、<材质：布艺/皮革/金属/木质/玻璃等>与光泽一致，比例真实、不变形、不拉伸。
其余空间用协调的现代简约软装与中性配色衬托，使该产品成为视觉焦点，自然窗光，专业室内实景摄影质感，
高细节，透视正确。画面干净，不要任何文字、水印、角标、品牌字样或 logo。
```
负向词 B：
```
正对尽头墙, 走廊式正面, 扁平视角, 侧墙开窗, 左右墙落地窗, 比例与户型图不符,
造型失真, 比例失调, 拉伸变形, 颜色漂移, 材质不符, 同款产品重复出现, 把家具当地墙, 多余隔墙,
杂乱背景, 品牌文字, 水印, logo, 卡通, 塑料感
```

> 模板中的 `<…>` 全部由 Phase 0/1/2 的判读结果填入；**不要把某次 demo 的具体值（颜色 HEX、背景墙、空间名）当默认写死**。

### Phase 4 · 异常复核（默认跳过）
n=1 无择优环节，**默认直接进 Phase 5**。仅当出图结果**肉眼明显异常**（结构错乱、颜色严重漂移、产品造型失真、出现文字/logo）时，用 `image_read` 对照产品图复核一次：
- **表面材质类**：颜色/质感是否贴产品、有无涂抹斑块/镜面反光/水平色差带。
- **单体产品类**：造型/比例/结构是否忠实、颜色与材质是否一致。
- **取景核查**：是否为 Phase 2.5 设定的对角斜视机位、主采光面方位、长宽比是否贴户型图。

复核确认不达标 → 调提示词/换 seed 重跑，**最多重跑 1 次**，不无限打磨；重跑仍不达标就如实交付并说明可调项。

### Phase 5 · 交付
生成图已随 `image_render` 结果自动交付到会话（图片消息）。**最终回复不超过 3 句**：推荐点 + 一句可调项，禁止"这次是怎么落地的""说明一下"等章节化长解释与任何标题。**企业微信客服渠道（wecom_kf，系统提示词会标注）完全不输出文字，仅交付图片**。透明说明仅在客户问及时简要回答：3D 为视觉近似，尺寸与朝向以户型图为准；产品颜色以参考图锁定；会话界面"AI生成"角标为前端显示标识（租户可开关），图片文件本身无水印。

## 验证
- 交付前确认：产品主色/材质/（单品的）造型与参考图肉眼一致；**表面材质类**无涂抹斑块/镜面反光/水平色差带，**单体产品类**无变形/比例失调/同款重复；房型与户型图方位一致；无品牌文字/logo。
- 若用了 Phase 2 取色，核对提示词里的 HEX 与样块一致。

## 不要使用本技能
- 需要度量级精确尺寸/坐标的 2D 布局图、施工图 → 几何/绘图任务，找主智能体。
- 纯图片编辑（抠图、改背景、去水印、人像处理）→ 非本技能范围。
- 不涉及户型图/空间场景的产品展示图（如白底商品图）→ 直接文生图需求，无需本技能工作流。
