# 研学旅游报价生成技能

## 适用场景

当用户需要为研学旅游行程计算费用、生成报价单、或调整已有报价时使用此技能。典型触发词包括："报价"、"费用多少"、"算一下价格"、"报价单"、"成本核算"等。

## 报价计算规则

**以下计算规则必须严格遵守：**

- **按团均摊项目**（单位为"团"）：费用小计 = 单价 ÷ 总人数 × 次数
- **按人计算项目**（单位为"人"）：费用小计 = 单价 × 次数
- **住宿特殊计算**（单位为"间"或名称含"住宿"/"酒店"）：费用小计 = 单价 ÷ 2 × 夜数（两人一间标间）
- **总费用** = Σ 费用小计

所有费用小计保留2位小数。

## 六大成本类别

| 类别 | 说明 | 计算方式 |
|------|------|---------|
| 用车 | 大巴包车等交通费用 | 按团均摊 |
| 用餐 | 餐饮费用 | 按人 × 餐数 |
| 住宿 | 酒店/民宿住宿 | 按人 × 夜数，两人一间 |
| 门票/活动 | 门票、讲解费、研学课程 | 按人或按团 |
| 其他费用 | 保险/用水、研学导师、司陪房、老师费用、操作费 | 按项目不同 |
| 随队老师 | 老师费用单独列 | 按实际安排 |

## 使用说明

### Step 1：使用 knowledge_base_search 逐项检索价格数据

根据行程安排，逐项从知识库检索价格信息：

```
knowledge_base_search(query="天眼 门票 价格")
knowledge_base_search(query="贵阳 4钻 酒店 价格")
knowledge_base_search(query="大巴 费用 包车")
knowledge_base_search(query="研学导师 费用")
knowledge_base_search(query="保险 费用 研学")
```

### Step 2：调用 calculate 脚本计算

将检索到的价格数据整理为报价项列表，调用计算脚本。**当报价项较多时，必须通过 stdin 传递 JSON 数据，避免命令行参数过长被截断：**

```
skill_execute(
  skill="quote-generator",
  command='python scripts/calculate.py --people 30',
  content='[{"category":"用车","name":"旅游大巴","unit_price":9800,"quantity":1,"unit":"团","frequency":1,"freq_unit":"次","remark":"40座6天全程"},{"category":"用餐","name":"研学正餐","unit_price":40,"quantity":1,"unit":"人","frequency":8,"freq_unit":"餐","remark":"标准餐标"}]'
)
```

**重要：使用 `content` 参数传 items JSON 数组，不要用命令行 --items 参数！** content 参数会通过 stdin 传给脚本，不受命令行长度限制。

### Step 3：输出结构化报价表

根据计算结果，按标准格式生成报价表展示给用户。

## 报价输出格式

```
贵州天悦旅行社有限公司研学报价表

课程名称：XXX    日期：XXX    人数：XX人

| 成本类别 | 项目 | 单价 | 数量 | 单位 | 次数 | 单位 | 费用小计 | 随队老师 | 备注 |
|---------|------|------|------|------|------|------|---------|---------|------|
| 用车 | 旅游大巴 | 9800 | 1 | 团 | 1 | 次 | 326.67 | - | 40座6天全程 |
| 住宿 | 贵阳4钻酒店 | 380 | 1 | 间 | 2 | 晚 | 380.00 | - | 含早 |
| ... | ... | ... | ... | ... | ... | ... | ... | ... | ... |

合计：XXXX元/人
```

## 注意事项

- **价格必须来自知识库**：所有单价数据必须通过 knowledge_base_search 从知识库检索，不得凭空编造价格
- **保留2位小数**：所有费用小计和总费用均保留2位小数
- **注明价格来源**：每项报价应在备注中注明价格来源（如知识库文档名称）
- **人数确认**：计算前必须确认总人数，不同人数会影响按团均摊的单价
- **住宿默认两人一间**：住宿费用按两人一间计算，如有单房需求需额外说明
