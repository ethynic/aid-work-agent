# 输出 xlsx 的格式约定（HBA FF&E 报价清单风格）

## 工作簿结构（3 张表）

1. 主表（本文件按业态命名）
2. `参数 Parameters`——驱动数量计算
3. `Notes 说明`

### 参数 Parameters 页

| 位置 | 内容 |
|---|---|
| A1:C1 | 标题 |
| 第 3 行 | 表头：参数名称 / 数值 / 说明 |
| 第 4 行起 | 每个参数一行：**B 列为填写区（浅黄底）**，C 列写来源或"待谁提供" |

主表数量列用公式引用 B 列，如 `=IF('参数 Parameters'!$B$9="","",'参数 Parameters'!$B$9*(1+0.05))`。
**参数为空 → 该行数量显示空白**；填入后全表联动重算。这是"不编造数据"与"尽量算出数量"的折中点。

## 页面骨架（主表）

| 区域 | 位置 | 说明 |
|---|---|---|
| 抬头区 | D1:D5（每行 D:H 合并） | 标题 / Project / Project # / Issue Date / By Area |
| 表头 | 第 6 行，A–L | 灰色底 `D3D3D3`、Arial→微软雅黑 9 号加粗、thin 边框、自动换行 |
| 区域分组行 | 每条分组一条 | A:G 合并，灰底加粗，写"编号 英文名 中文名" |
| 数据行 | — | A 编号、B 描述、C:D 区域（合并）、E 数量、F 单位、G 品牌、H 图片、I 单价、J 合价、K 数量依据、L 依据 |
| 合计行 | 末尾 | A:I 合并写 "Total 合计"，J 写 `=SUM(J7:J倒数第二行)` |

- 列宽：A11 / B48 / C20 / D8 / E8 / F9 / G20 / H15 / I12 / J13 / K30 / L18
- 冻结窗格 A7；横向打印、适合一页宽；重复表头行 6

## 必填规则

- **E（数量）优先用公式算出**：由参数页驱动（见上），算不出的行才留空并用浅黄 `FFF7DC` 标记。
- **I（单价）一律留空 + 浅黄填充 `FFF7DC`**：由供应商填写。
- **J（合价）用公式**：`=IF(OR(E{r}="",I{r}=""),"",E{r}*I{r})`，数量与单价都填后自动出合价。
- **B 描述结构**：
  1. 第一行 `中文名  英文名`
  2. 若干条 `• 英文规格`
  3. 空行 + `中文说明：…`
  4. 空行 + `供货责任 Scope：甲供 Owner Supplied / 乙供 Contractor / 待确认 TBC`

## 行高必须自己算

wrap_text + 合并单元格时 Excel/WPS 不会自动适应行高，需估算：

- 中文字符记 2 个宽度单位，ASCII 记 1 个；
- 每行需要的显示行数 = `ceil(累计宽度 / (列宽 - 2))`；
- 行高 = `最大(16, 行数 × 12.5 + 4)`，有图片时再取 `max(行高, 图高 × 0.78 + 8)`，上限 300。

## 每张表附 Notes 说明页

内容至少包括：编制依据（含手册版本与页码）、数量/单价填写规则、货币与价格口径、
甲供乙供划分、品牌替代审批、尚需业主补充的信息清单、本文件涵盖的空间范围。

## 其他

- 中文字体统一 `Microsoft YaHei`，表头 9 号加粗，正文 8 号。
- 生成后必须 reopen 校验：sheet 数、行列数、图片数、合并单元格、必填列是否为空、抽查描述是否截断。
