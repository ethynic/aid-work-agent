## 1. 概述

### 什么是微信客服

微信客服场景是指企业员工通过企业微信添加外部客户的微信，建立一对一沟通。本功能让 AI Agent 接管指定的客服账号，自动与外部微信客户对话。

```
外部微信客户 ←→ 企业微信客服系统 ←(API)→ Our Agent ←→ 子智能体
```

### 与企业微信内部应用的区别

| | 企业微信内部应用（已有） | 微信客服（本功能） |
|---|---|---|
| **服务对象** | 企业内部员工 | 外部微信客户 |
| **客户入口** | 工作台点击应用 | 微信中点击客服链接/扫二维码 |
| **消息通道** | 应用消息 API | 微信客服 API |
| **回调地址** | `/t/{tenant_id}/wecom/callback/{config_id}` | `/t/{tenant_id}/wecom-kf/callback/{config_id}` |

### 回调地址

| 方法 | 路径 | 说明 |
|------|------|------|
| **GET** | `/t/{tenant_id}/wecom-kf/callback/{config_id}` | 验证回调 URL 有效性 |
| **POST** | `/t/{tenant_id}/wecom-kf/callback/{config_id}` | 接收消息和事件推送 |

系统会立即返回 `"success"`（毫秒级），消息处理在后台异步执行，不受企微 5 秒响应要求的限制。

## 3. 企业微信管理后台配置

### 步骤 1：开启微信客服功能

1. 登录 [企业微信管理后台](https://work.weixin.qq.com/wework_admin/frame)
2. 进入「应用管理」→「微信客服」
3. 确认微信客服功能已开启

### 步骤 2：创建自建应用

1. 进入「应用管理」→「自建」→「创建应用」
2. 填写应用名称（如「AI 智能客服」）、logo、可见范围
3. 创建完成后，记录以下凭证：

| 凭证 | 位置 | 格式示例 |
|------|------|----------|
| **CorpID** | 「我的企业」→「企业信息」 | `ww2ed7298c926e081c` | 1000005
| **Secret** | 应用详情页 → 点击「查看」 | TAvsg5z0vFX5kCesjQUkQN0plhtT7zb6PkD5TOeuKJY |

> **注意**：微信客服场景下，**不需要** AgentId，Secret 使用的是步骤 2 中创建的**自建应用的 Secret**。在步骤 3 中，该自建应用会被设置为「可调用接口的应用」，从而获得微信客服 API 的调用权限。

### 步骤 3：设置微信客服 API 管理

1. 进入「微信客服」→「通过 API 管理」
2. 开启「通过 API 管理微信客服账号」
3. 在「可调用接口的应用」中，选择步骤 2 创建的自建应用

### 步骤 4：创建客服账号

1. 进入「微信客服」→「客服账号」→「添加客服账号」
2. 填写客服账号名称（如「售前咨询」）
3. 创建成功后，**记录客服账号名称**，后续通过 API 获取对应的 `open_kfid`（格式如 `wkAAAA`）

> **说明**：企业微信后台通常不直接显示 `open_kfid`，需要调用「获取客服账号列表」接口获取。可以创建多个客服账号，每个绑定不同的子智能体。例如：售前咨询、售后服务、技术支持等。

### 步骤 5：配置回调 URL

1. 在「微信客服」→「API」中找到回调配置
2. 填写以下信息：
   - **URL**：`https://your-domain.com/t/{tenant_id}/wecom-kf/callback/{config_id}`
     - `your-domain.com`：替换为实际域名
     - `tenant_id`：租户 ID（在 Our Agent 管理后台查看）
     - `config_id`：渠道配置 ID（先在 Our Agent 后台创建渠道配置后获得）
   - **Token**：点击「随机获取」或自行设置
   - **EncodingAESKey**：点击「随机获取」（43 位 Base64 字符串）
3. **先不要点保存**——需要先在 Our Agent 后台完成配置后再回来保存

### 步骤 6：配置可信 IP

1. 在应用详情页，找到「企业可信 IP」
2. 添加 Our Agent 服务器的公网 IP 地址

### 步骤 7：设置接待方式

1. 进入「微信客服」→「客服账号」→ 选择具体客服账号
2. 设置「接待方式」为「**机器人+人工接待**」
3. 这样该客服账号的消息才会通过 API 推送，Agent 才能接管

> **关键**：如果设置为「仅人工接待」，消息不会通过 API 推送，Agent 无法收到消息。

## 4. Our Agent 管理后台配置

### 4.1 添加微信客服渠道

1. 登录 Our Agent 管理后台
2. 进入租户设置 →「渠道配置」
3. 点击「添加渠道」→ 选择「**企业微信客服**」

### 4.2 填写基础凭证

| 字段 | 说明 | 获取位置 |
|------|------|----------|
| **corp_id** | 企业 ID | 企微后台「我的企业」 | ww2ed7298c926e081c 1000005
| **secret** | 自建应用 Secret | 企微后台「自建应用」→「Secret」 | TAvsg5z0vFX5kCesjQUkQN0plhtT7zb6PkD5TOeuKJY
| **token** | 回调 Token | 步骤 5 中设置的 Token | YT3ln8iWl2J1GmikjtrPUwEfuLP
| **encoding_aes_key** | 回调加密密钥 | 步骤 5 中设置的 43 位 Key | IInKz1vCBGkybcyepYfHrgsAcliMPqIQVgCWRwzl8V9

### 4.3 配置客服账号

每个客服账号需要单独配置：

| 字段 | 说明 | 示例 |
|------|------|------|
| **客服账号名称** | 便于识别的名称 | 售前咨询 |
| **open_kfid** | 客服账号 ID | `wkAAAA`（步骤 4 中获得） |
| **绑定子智能体** | 该客服入口使用哪个 Agent | 下拉选择已部署的子智能体 |
| **欢迎语** | 客户首次进入时自动发送的消息 | "您好，我是 AI 智能客服，请问有什么可以帮您？" |
| **人工接待人员** | 可转接的企微员工账号 | 填入企微 userid，如 `zhangsan` |
| **转人工关键词** | 触发人工转接的关键词 | `人工服务`、`转人工`、`人工客服` |

**配置示例（两个客服账号）**：

```
客服账号 1：
  名称：售前咨询
  open_kfid：wkAAA123
  绑定子智能体：sales-consultant
  欢迎语：您好，我是售前咨询助手，请问有什么可以帮您？
  人工接待人员：zhangsan, lisi
  转人工关键词：人工服务, 转人工

客服账号 2：
  名称：售后服务
  open_kfid：wkBBB456
  绑定子智能体：after-sales
  欢迎语：您好，我是售后助手，请描述您的问题。
  人工接待人员：wangwu
  转人工关键词：人工服务, 转人工, 投诉
```

### 4.4 获取回调地址并验证

1. 配置保存后，系统自动生成回调 URL：
   ```
   https://your-domain.com/t/{tenant_id}/wecom-kf/callback/{config_id}
   ```
2. 复制该回调 URL
3. 回到企业微信管理后台（步骤 5），将回调 URL 粘贴到「URL」栏
4. 点击「保存」→ 企微发送 GET 验证请求 → 系统自动响应 → 验证通过

### 4.5 获取客服链接

客服账号创建后，可以在企微后台「客服账号」页面获取客服链接（https://work.weixin.qq.com/kfid/kfc099fb6554cad1701），配置到：

- 公众号菜单
- 小程序页面
- 网站/落地页
- 视频号主页
- 企微员工名片

客户通过这些入口即可发起与 AI Agent 的对话。

## 5. 消息限制说明

### 5.1 企微 API 限制

| 限制 | 说明 | 应对措施 |
|------|------|---------|
| **48 小时回复窗口** | 客户主动发消息后 48 小时内可回复，超时无法回复 | 无需特殊处理，多数客服场景在 48 小时内完成 |
| **5 条消息/次** | 客户发消息后，最多可发 5 条；客户再发消息则刷新额度 | Agent 长回复会自动分段发送，控制不超过 5 条 |
| **单条消息 2048 字节** | 单条文本消息不超过 2048 字节 | 超长文本自动分段 |
| **不支持 Markdown** | 微信客服消息不支持 Markdown 格式渲染 | 自动将 Markdown 转为纯文本发送 |
| **3 天消息保留** | sync_msg 只能拉取 3 天内的消息 | 系统收到消息即存入数据库，不依赖企微保留 |

### 5.2 文件消息

Agent 生成的文件会以**图文链接卡片**形式发送：

```
┌──────────────────────┐
│ 📄 report.docx       │
│ 点击下载 (12KB)       │
│          [卡片样式]    │
└──────────────────────┘
```

客户点击卡片后在浏览器中下载文件。文件下载链接有效期为 1 小时。

## 6. 用户身份管理

### 6.1 自动创建用户

客户首次通过微信客服发起对话时，系统自动创建用户账号：

| 字段 | 值 | 说明 |
|------|------|------|
| 用户名 | 微信昵称 | 从企微 API 获取 |
| 来源 | `wecom_kf` | 标记来自微信客服渠道 |
| 手机号 | 空 | 企微 API 不提供外部用户手机号 |
| 微信 ID | `wmXXXX` | external_userid，记录在 metadata 中 |

### 6.2 手机号补全

- 如果客户在对话中主动提供了手机号，Agent 可更新用户信息
- 如果手机号与已有用户匹配，自动合并账号
- 后续可扩展：通过小程序授权获取手机号

### 6.3 CRM 关联

如需将微信客服客户与 CRM 系统关联，可引导客户在对话中提供手机号或其他唯一标识。

## 7. 人工转接配置

### 7.1 自动转人工触发条件

以下情况会自动触发人工转接：

| 触发方式 | 说明 |
|---------|------|
| **关键词触发** | 客户说"人工服务"、"转人工"等（可自定义关键词） |
| **Agent 主动转接** | Agent 调用 `transfer_to_human` 工具（识别到投诉情绪等） |

### 7.2 配置人工接待人员

1. 在客服账号配置中填写「人工接待人员」
2. 填入企微员工 userid（可在企微后台「通讯录」中查看）
3. 可以配置多个接待人员，转接时分配给第一个在线的

### 7.3 转接流程

```
客户说"人工服务"
    │
    ▼
Agent 回复："正在为您转接人工客服，请稍候..."
    │
    ▼
系统调用企微 API 变更会话状态 → 转给人工接待人员
    │
    ▼
人工客服在企微端接管会话，后续消息不再经过 Agent
    │
    ▼
人工客服结束接待后，会话自动回到"智能助手接待"模式
后续客户消息再次由 Agent 处理
```

## 8. Nginx 配置

微信客服回调路由与现有企微路由并存，在 Nginx 配置中添加：

```nginx
server {
    listen 443 ssl;
    server_name your-domain.com;

    # 现有企微应用回调
    location ~ ^/t/([^/]+)/wecom/callback/([^/]+)$ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # 微信客服回调（新增）
    location ~ ^/t/([^/]+)/wecom-kf/callback/([^/]+)$ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # ... 其他 location 配置 ...
}
```

> 回调请求体可能较大（含加密 XML），确保 `client_max_body_size` 不小于 1MB。

配置完成后重载 Nginx：

```bash
sudo nginx -t && sudo nginx -s reload
```

## 10. 故障排查

### 回调验证失败

**现象**：企微后台点保存时提示"URL 验证失败"

| 检查项 | 排查方法 |
|--------|---------|
| 回调 URL 格式 | 确认格式为 `/t/{tenant_id}/wecom-kf/callback/{config_id}` |
| HTTPS 证书 | 浏览器访问域名，确认证书有效 |
| 服务是否运行 | `curl https://your-domain.com/health` |
| Nginx 代理 | 检查 Nginx 日志是否有 502/504 |
| Token/AES Key | 确认企微后台和 Our Agent 后台填写一致 |
| 防火墙 | 确认 443 端口对外开放 |

### 收不到客户消息

| 检查项 | 排查方法 |
|--------|---------|
| 接待方式 | 确认客服账号设为「智能助手接待」而非「人工接待」 |
| API 管理开关 | 确认「通过 API 管理微信客服账号」已开启 |
| 应用权限 | 确认自建应用在「可调用接口的应用」列表中 |
| 可信 IP | 确认服务器 IP 已添加到可信 IP 列表 |
| 后端日志 | 查看后端日志是否有回调请求记录 |

### Agent 回复发送失败

| 检查项 | 排查方法 |
|--------|---------|
| 48 小时窗口 | 客户超过 48 小时未发消息，无法回复（企微限制） |
| 5 条消息限制 | 客户发消息后 Agent 已发 5 条，需等客户再发消息 |
| Token 过期 | 查看后端日志是否有 token 刷新失败 |
| Secret 正确 | 确认使用的是自建应用的 Secret |

### 人工转接不生效

| 检查项 | 排查方法 |
|--------|---------|
| 接待人员配置 | 确认「人工接待人员」中填写了正确的企微 userid |
| 接待人员在线 | 确认该员工企微客户端在线 |
| 关键词匹配 | 确认「转人工关键词」中包含客户使用的词 |
| 子智能体指令 | 确认子智能体的 system_prompt 中包含转人工指令 |

### 文件下载失败

| 检查项 | 排查方法 |
|--------|---------|
| 链接过期 | 临时下载链接有效期 1 小时，过期需重新发送 |
| 文件服务可达 | 浏览器直接访问文件下载 URL，确认能下载 |
| CORS 配置 | 确认 Nginx 未阻止文件下载请求 |
