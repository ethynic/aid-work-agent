## 范围与验收

按[微信 CLI 设计](../design/weixin/weixin-cli-design.md#12-本机添加好友)实现。参考随需求提供的 Workbuddy 微信加好友 skill v2.0.0 的操作次序和结果类型，微信窗口定位、写入、取消与计费使用第一方 CLI 现有架构。

1. CLI 接收一个手机号或微信号，支持可选验证语及现有 JSON 结果外层。非空标识修剪后传给驱动，验证语全文不进入日志。
2. Windows 驱动验证微信窗口身份，逐步定位当前控件。已有好友、已申请、无结果或无法判断时不提交。能确认申请已提交或好友已添加时才返回 `applied`，提交阶段丢失证据时不得自动重放。
3. 通过现有客户端绑定与服务端代理获取视觉坐标，保留凭据错误和余额不足语义。验收需检查出现直调密钥时仍只走服务端。
4. 跑 CLI 构建与回归、PowerShell 语法和受控交互测试。真实微信申请、窗口结果及积分账单需用获授权的测试好友和有效的计费绑定验收。验收通过前不加入对外 Provider 工具声明。

## 验证记录

- Windows 原生 `npm test` 通过 219/221 项。改动前的 214 项有两个同样的失败，分别来自 `name-search-native` 缺少搜索浮层夹具和 `ocr-text-independent` 重叠对象对齐。
- 新增 CLI 参数、PowerShell 状态流转及回环计费代理测试 7/7 通过。Windows PowerShell 5.1 语法、CLI 启动、MCP 兼容性测试也通过。
- 回归夹具复现了模型等待期间同窗更换目标导致的误点击。增加本地截图复查后，目标变化会在写入前停止，回执画面变化返回 `unknown`，光标短暂闪烁仍可通过。
- 在微信 4.1.15.13 用本机回环代理返回坐标，验证实际菜单、搜索框和回车。合成标识显示「找不到相关账号或内容」，修复后的命令返回 `TARGET_NOT_FOUND`。模拟余额不足在键入前停止。未对真实联系人提交申请，未消耗实际积分。
