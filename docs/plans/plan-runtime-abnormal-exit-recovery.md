## 怎么验收

- **旧进程已经退出。** 在 Windows 上让 Runtime 异常退出，再通过原自启入口启动。复测原会话的受管进程组退出、跨会话取得受管退出回执或原会话已无进程。原设备应自动上线，并实际领取一条测试任务。对照一次正常启动。
- **旧进程尚未退出或查询暂时失败。** 等待期间不启动第二份执行，确认旧进程退出后自动接单。首次查询临时失败时，下次复查可继续恢复。
- **旧记录损坏或缺失。** 初查和复查都应停止自动恢复，显示明确失败并保留原记录。Windows 重启不能替代旧执行退出的证明。
- **恢复过程中主动停止或退出。** 旧执行的退出结果晚到，或显式停止成功后，Runtime 保持用户所选状态。上一次结果不明的动作不会因恢复而重做。
