## 怎么验收

- **旧进程已经退出。** 在 Windows 上让 Runtime 异常退出，再通过原自启入口启动。分别复测原登录会话已注销、旧标记或凭据读不出（损坏归档放行）。原设备应自动上线，并实际领取一条测试任务。对照一次正常启动。
- **旧进程尚未退出。** 等待期间不启动第二份执行，旧进程退出后自动接单。再验证一次系统查询暂时失败后能够自动恢复（首次查询失败也进入复查）。
- **恢复过程中主动停止或退出。** 用户点「停止执行」或退出后，本轮自动启动被取消；检查结果晚到时，Runtime 也不会重新启动。上一次结果不明的动作不会因恢复而重做。
