复用现在的启动入口和进程检查。启动时核实上次的执行进程，确认退出就继续启动，暂时无法确认就自动再查。

## 怎么验收

- **旧进程已经退出。** 在 Windows 上让 Runtime 异常退出，再通过原自启入口启动。分别复测原登录会话已注销、旧记录损坏但能确认 Windows 已完整重启。原设备应自动上线，并实际领取一条测试任务。对照一次正常启动。
- **旧进程尚未退出。** 等待期间不启动第二份执行，旧进程退出后自动接单。再验证一次系统查询暂时失败后能够自动恢复。
- **恢复过程中主动退出。** 检查结果晚到时，Runtime 也不会重新启动。上一次结果不明的动作不会因恢复而重做。
