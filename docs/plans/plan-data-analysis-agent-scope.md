## 1. 目标、假设与完成条件

默认本租户全部智能体可用；配置名单后，仅本租户名单中的智能体可通过数据分析功能使用该表。按注册表 doc_id 配置，Excel/CSV 和数据库表一致。允许选一个或多个智能体，主智能体以 main 标识。

本期是数据分析功能及表元数据检索的使用范围，不是同租户文件系统隔离；不撤回历史聊天和下载，不强制中断正在运行的分析。不改变用户权限或主/子智能体委托语义。以上边界需在交付说明中保留。

开发完成需同时满足：

1. 未配置的存量表不迁移、不重新向量化，租户内共享行为不变。
2. T/A 能分析限定给 A 的 Excel/数据库表；T/B 不可自动发现、搜索、显式加载或通过历史分析产物复用这些表；直接传入 source 不得绕过。
3. 通用知识检索不泄露受限表 Schema；受限表移到其他栏目后仍执行名单，管理员仍能修改配置。
4. 恢复共享后后续分析重新可用；Schema 普通编辑和重复导入不意外恢复共享。
5. 原跨租户共享的空名单表行为不变；限定表不能因两租户智能体 ID 相同而被另一租户使用。
6. 前端在原页可完成配置；默认共享新增操作为0，导入本批只设置一次，已有多表支持一次批量设置；无权限/保存失败有明确反馈。
7. 相关定向测试、前端构建及独立测试/CR完成，有可核验结果；更新本计划与索引。未验证项如实记录。

## 2. Phase 0：已核对事实与需要避免的误判

- 入口是 `frontend/web/pages/DataSourceManager.vue`，不是 `TenantDataSources.vue`（后者是商城同步授权）。
- documents.metadata 实际为 TEXT/JSON；已有 source 存在 dict 和聊天附件字符串两种形态；新字段不能要求旧表先规范化。
- 知识库栏目授权对分析工具有明确豁免，不能直接复用栏目选择实现本需求。
- analyze_data 在表数不超过50时全量预加载；过滤必须发生在计数、选表与加载之前。
- 显式传 source 会绕过回查；DataAnalyzer 支持原始路径读取；load_output 只查租户路径；这些是本需求直接相关的入口。
- 管理 schemas 列表/更新/删除只按原 source_type，移动后的表目前可能仍能分析却无法在该页面管理。
- 当前执行链没有原文档所述三级 DataFrame 缓存，不以新增缓存或失效广播解决范围变更。
- 原「数据源导入」完成条目的计划链接目标当前缺失；本任务新建本计划，不重写历史完成记录。

调研结论已经收敛进原设计 §18.2；不另建重复调研报告或进度文档。

## 4. Phase 2：运行时统一生效

按依赖顺序实现，不能只完成界面隐藏就交付：

1. **身份与列表/单表回查**：ToolExecutionContext 优先，main 的转换只在可信上下文存在时进行；无工具身份只用共享表并返回诊断提示，不自动给生产脚本补 main；query_data_tables_list/fetch_table_metadata_from_db 在完整原范围外 AND 名单，不放宽既有共享分类。
2. **预加载与显式表**：显式 tables_metadata 只保留 ID 作为选择依据，全部回查，不使用调用方 source；所有指定表校验通过后才开始物理加载。自动列表先过滤，再走50/30阈值原策略。
3. **语义/文件名检索**：HybridRetriever → VectorDatabase/FTS、KnowledgeBaseService 标题/内容检索新增可选可信 agent_id；工具传递身份，共用 SQL 条件，排名/LIMIT 前过滤。analysis_agent 的批量 metadata 回查和 fallback 同步使用范围。
4. **读取路径**：analyze_data 的 DataAnalyzer 禁用任意路径 source，仍支持已加载表/变量；源文件由授权表加载；连接器按服务端文档来源租户校验，保留已授权跨租户共享表读取。
5. **产物**：按直接输入来源做 source_table_ids 集合传播及注册，独立常量上限200；超限/未知为 null，未知持续传播，当前计算继续但不跨调用复用。跨调用清单、export-only 判定、等价产物提示、load_output 统一用会话登记和当前源表范围验证。旧无完整来源记录不复用，明确提示重算；不新增历史文件清理/宽限机制。
6. **进行中变更**：每次尚未加载表的 load_table 都回查当前范围，然后才检查等价产物提示；新 load_output 按当前来源范围，已在内存的表/变量不撤回。不增加整次授权快照和轮询，检查与物理读取间变化不跨资源长事务锁定。

检查点：用确定性 fake LLM 驱动实际工具链，可用表正常完成 pandas 分析，不可用表不会进入模型清单或触发文件/数据库读取。批量查询来源 ID；不能对每个产物每个源表循环查库。权限读取失败明确返回错误，不当成「没有配置」。

不重写 AgentEngine、Runner、工具协议或多表计算引擎；不实现全工具文件权限和运行中强制撤销。

| 并发和重复 | 普通 Schema 编辑与范围保存交错后范围不丢失；重复上传返回已有真实范围，不覆盖为共享 |

| UI 默认成本 | 不修改范围直接完成原导入步骤，新增点击/必填/确认均为0；目录加载失败也不阻止未改范围的默认导入 |

| UI 批量配置 | 同一弹框一次设置多表；混合范围必须明确选择目标；替换含义可见；部分失败统计准确、成功不重试；翻页/筛选/切租户清空选择 |

| UI 跨租户提示 | 租户级布尔值只在指定模式控制一句条件说明，不能声称单表正被外部使用；接口只做一次 EXISTS，普通默认导入没有新提示/配置步骤 |
