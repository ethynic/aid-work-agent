# Runtime 异常退出后如何恢复

2026-11-11 · 评审修订

Runtime 异常退出后，会留下上次的运行记录。国腾现场已经重启，旧执行进程也已退出，Runtime 却仍显示「待核对」，一直无法接单。[现场记录](../incidents/guoteng-runtime-disconnect-20261110.md)

## 怎么恢复

1. 登录自启或用户打开 Runtime 时，如果发现上次异常退出，就核对旧运行标记和进程台账。在原登录会话内确认受管进程组已退出。跨登录会话时，可用匹配的退出回执，或确认原会话已无进程。退出回执只覆盖受管进程组。Windows 重启不作为自动恢复依据。旧运行标记或台账损坏、缺少必要记录时，提示恢复失败并保留原记录。
2. 确认旧执行已退出，就把旧记录留作历史，用原配对恢复心跳和接单。即使 Windows 换了登录会话，也以旧进程是否已经退出为准。
3. 旧执行还在运行时，沿用现有的停止方式，只停止能确认是上次 Runtime 留下的执行进程。从第一次核对起，旧进程尚未退出或系统查询暂时失败时，显示「正在确认上次的执行是否已退出」，自动再查。用户主动停止或退出时，取消本次自动启动，随后返回的检查结果不得触发接单。

恢复接单后，上次结果不明的动作不会自动重做。
