# Runtime 异常退出后如何恢复

2026-11-11 · 待评审

Runtime 异常退出后，会留下上次的运行记录。国腾现场已经重启，旧执行进程也已退出，Runtime 却仍显示「待核对」，一直无法接单。[现场记录](../incidents/guoteng-runtime-disconnect-20261110.md)

## 怎么恢复

1. 登录自启或用户打开 Runtime 时，如果发现上次异常退出，就用旧记录里的进程组编号，查这组插件进程还有几个在运行。跨登录会话时，可用上次的退出回执，或确认原会话已注销。读不出编号时，能独立确认 Windows 在上次运行之后已完整重启，也可以直接恢复。
2. 确认旧执行已退出，就把旧记录留作历史，用原配对恢复心跳和接单。即使 Windows 换了登录会话，也以旧进程是否已经退出为准。
3. 旧执行还在运行时，沿用现有的停止方式，只停止能确认是上次 Runtime 留下的执行进程。正在退出或系统暂时查不到时，显示「正在确认上次的执行是否已退出」，自动再查。确认退出后直接恢复。用户主动停止或退出时，结束本次恢复。

恢复接单后，上次结果不明的动作不会自动重做。
