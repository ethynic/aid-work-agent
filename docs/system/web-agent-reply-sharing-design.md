# Web Agent 单条回复分享设计

> 2026-10-22：按用户确认的简化方案实施，恢复此前未保留在工作区的设计记录。
> 开发计划：[回复分享开发计划](../plans/plan-web-agent-reply-sharing.md)

## 功能与使用流程

用户在某条 Agent 回复下方点击「分享」（链接图标），选择对方是否需要密码，生成链接并复制。接收方无需登录，在独立网页查看选中的这一条回复；有密码时先验证。文字、Markdown、图片、普通外链、附件卡片、既有附件预览及下载必须完整支持，纯图片/纯附件回复同样可分享。

2026-10-22 UI 调整：回复下方将时间和「链接图标＋分享」排在同一条轻量操作栏，按钮使用小字号，无常驻外框，键盘操作保留可见焦点。分享弹框使用紧凑宽度、16px 标题与12–14px内容层级，隐藏全屏入口。默认选择「无需密码」，两个访问方式以带图标和选中标记的卡片并排展示；选择密码时用现有安全随机源生成6位易读大写字母数字码（避开0/O/1/I等混淆字符），明文等宽展示，支持修改及主动换一组。生成后链接与密码分开显示，主按钮一起复制，另保留仅复制链接入口；复制失败仍可选中链接手动复制。

只做这一条回复的独立展示，不增加有效期选择、分享中心、访问统计、版本管理、发布预览或访客管理。当前弹框重复复制复用刚生成的链接，再次分享可按当次选择创建链接。

## 复用现有展示

从 `MessageItem.vue` 中提取 `ReplyContent.vue`，聊天与分享共同使用。复用现有 Markdown、ImageGallery、AttachmentChip、DownloadFileCard 和 AttachmentPreviewPanel；通过可选资源地址解析参数接入分享文件地址，不复制一套精简渲染器。

分享页不挂载聊天输入框、执行进度、原会话的提问/工具操作。共享 Markdown 做同一套基础 HTML 消毒，保留正常排版、图片和链接；HTML 附件使用隔离的既有预览容器。

## 数据与接口

新增系统表 `chat_message_shares`：随机 share_key、可信 tenant/user、源 session/message、reply_data、可空 password_hash、created_at。保存本条回复的展示副本和资源引用，不复制文件或整个会话。源数据从服务端已持久化 Web 消息取得，复用 owned_web_session 确认归属；Web 的 Runner 投影 ID 在 Web 适配层解析，不修改 Runtime/Runner 契约。

最终 Runner 回复从所属 Web Runner 已持久化的 `result/public_snapshot` 读取，与聊天的投影口径一致；纯附件回复即使没有单独的历史 assistant 行也可分享。普通历史回复仍按选中的物理消息 ID 读取，不读取 Runner 私有 checkpoint。

| 接口 | 行为 |
|------|------|
| `POST /api/sessions/{session_id}/messages/{message_id}/share` | 可选 password，创建分享并返回 share_key、share_path |
| `POST /api/public/reply-shares/{share_key}/view` | 无需密码/正确密码时返回完整 message 和资源访问票据，否则返回需要密码或错误 |
| `GET /api/public/reply-shares/{share_key}/files/{asset}` | 验票并按本条回复的资源清单提供预览或下载，download=1 为下载 |

密码复用现有 bcrypt。资源访问复用既有下载路径签名，分享页一次验证即可查看图片、预览及下载，不逐文件要求密码；签名覆盖正常阅读时间，不新增 Cookie 或 Redis 访客会话。现有其他下载票据默认期限不变。

图片和附件使用分享内资源别名，避免公开原始内部直链绕过分享密码。外部图片/文件沿用原网址，必要时经资源入口验票后跳转，不增加抓取代理。资源仅限这条回复实际关联的内容，不开放租户文件库。保留文件原有存储生命周期；文件不存在时明确提示，不静默删卡片。

Markdown、HTML、SVG 及 HTML 样式中引用的站内图片与相对文件一并登记，预览时使用同一分享资源入口；下载保留附件原始字节。地址识别兼容百分号编码、HTML 实体及属性大小写，按完整引用的位置改写，外域地址保持原样。文件归属复用现有租户存储范围与知识库共享授权；HTML/SVG 响应及 HTML 预览容器使用 sandbox，保留脚本展示能力并隔离站点身份。图片位置沿用聊天的 placement 回退规则，单图按页面宽度缩放。

## 验收

- 独立网页与聊天中选中回复的文字、图集、内嵌图片、附件及链接一致。
- 无需系统账号；正确密码后整条回复与资源一起可用，错误密码不返回受保护内容。
- 图片可放大，附件使用已有预览能力，原来只能下载的格式仍可下载。
- 不能通过修改文件标识读取本条回复之外的资源。
- 窄屏、文件缺失、密码错误及复制失败有准确反馈；原聊天展示不回归。

本次开发不包括服务器部署；开发完成后按计划记录实际验证结果。
