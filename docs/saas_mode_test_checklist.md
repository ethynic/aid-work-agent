# SaaS 模式测试要点

## 测试范围概述

| 维度 | 内容 |
|------|------|
| 模式 | 演示模式、SaaS 模式（生产模式） |
| 入口 | 演示入口 `/`、租户前台 `/t/{tenant_id}`、管理后台 `/portal` |
| 角色 | 平台管理员、租户管理员、租户普通用户、演示用户 |
| 重点 | 模式区分、入口隔离、角色权限、主线功能 |

---

## 一、模式区分测试

### 1.1 演示模式识别
- [ ] 访问 `/` 展示演示模式界面
- [ ] 演示模式显示"演示用户"标识或入口
- [ ] 演示模式不显示租户相关信息

### 1.2 SaaS 模式识别
- [ ] 访问 `/portal` 展示管理后台登录页
- [ ] SaaS 模式不出现演示模式的登录表单
- [ ] SaaS 模式正确区分 3 类入口（管理后台、租户前台）

### 1.3 模式切换
- [ ] 演示模式页面无跳转 SaaS 入口的强引导（除非明确设计）
- [ ] 各入口的认证状态相互独立，不互相干扰

---

## 二、入口隔离测试

### 2.1 演示入口 `/`
- [ ] 任意手机号 + 密码 `888888` 可登录（演示用户）
- [ ] 登录后进入演示聊天界面
- [ ] 演示用户**无法**访问 `/portal` 管理后台
- [ ] 演示用户**无法**访问其他租户前台 `/t/{tenant_id}`

### 2.2 管理后台 `/portal`
- [ ] 只有平台管理员和租户管理员可登录
- [ ] 平台管理员登录后可见所有租户列表
- [ ] 租户管理员和普通用户**无法**访问管理后台（被拦截或跳转）

### 2.3 租户前台 `/t/{tenant_id}`
- [ ] 需已创建的租户和有效用户账户
- [ ] 租户管理员可登录本租户前台
- [ ] 租户普通用户可登录本租户前台
- [ ] **无法**登录其他租户前台（跨租户隔离）
- [ ] 未登录用户访问 `/t/{tenant_id}` 被引导至登录页

---

## 三、角色权限测试

### 3.1 平台管理员（platform_admin）
- [ ] 可登录 `/portal`
- [ ] 可创建新租户及租户管理员
- [ ] 可查看所有租户列表和数据
- [ ] 可管理任何租户的智能体实例
- [ ] 可查看全局使用报告

### 3.2 租户管理员（tenant_admin）
- [ ] 可登录 `/portal`（本租户视角）
- [ ] 可创建本租户的普通用户
- [ ] **无法**访问其他租户数据
- [ ] 可管理本租户的智能体实例
- [ ] 可查看本租户使用报告

### 3.3 租户普通用户（tenant_user）
- [ ] **无法**登录 `/portal`
- [ ] 可登录 `/t/{tenant_id}` 使用智能体
- [ ] 可与智能体聊天（LLM 调用正常）
- [ ] **无法**创建或管理其他用户
- [ ] 只能看到自己的对话历史

### 3.4 演示用户（demo_user）
- [ ] 可登录演示入口 `/`
- [ ] 可使用演示智能体聊天
- [ ] **无法**访问 `/portal`
- [ ] **无法**访问 `/t/{tenant_id}`
- [ ] 对话数据与 SaaS 租户数据隔离

---

## 四、SaaS 模式主线功能测试

### 4.1 租户创建（平台管理员操作）
- [ ] 平台管理员登录 `/portal`
- [ ] 进入租户管理，创建新租户
- [ ] 为租户指定管理员（创建租户管理员账户）
- [ ] 租户创建成功，状态为"正常"

### 4.2 租户管理员创建普通用户
- [ ] 租户管理员登录 `/portal`
- [ ] 进入用户管理，创建普通用户
- [ ] 设置用户手机号、初始密码
- [ ] 普通用户使用上述凭证登录 `/t/{tenant_id}`

### 4.3 普通用户与智能体聊天
- [ ] 普通用户登录 `/t/{tenant_id}`
- [ ] 进入聊天界面，发送消息
- [ ] 智能体正常回复
- [ ] 对话记录正确保存

### 4.4 智能体实例管理（租户管理员）
- [ ] 租户管理员查看本租户智能体列表
- [ ] 可查看智能体状态（运行中/已停止）
- [ ] 可启动/停止智能体实例

---

## 五、数据隔离测试

### 5.1 租户间隔离
- [ ] 租户 A 用户**无法**看到租户 B 的任何数据
- [ ] 租户 A 用户**无法**访问租户 B 的智能体
- [ ] URL 直接输入跨租户 ID 被正确拦截

### 5.2 角色间隔离
- [ ] 平台管理员看不到租户普通用户的个人对话
- [ ] 租户管理员可看本租户汇总数据，但看不到具体用户对话
- [ ] 普通用户只能看到自己的对话

### 5.3 模式间隔离
- [ ] 演示模式数据与 SaaS 模式完全隔离
- [ ] 演示用户**无法**成为 SaaS 租户用户（反之亦然）

---

## 六、认证与会话测试

### 6.1 登录流程
- [ ] 演示模式：手机号 + `888888` 登录成功
- [ ] SaaS 管理员：配置手机号 + 密码登录成功
- [ ] 登录后 Token 正确存储

### 6.2 会话保持
- [ ] 刷新页面保持登录状态
- [ ] Token 过期后正确跳转登录页
- [ ] 退出登录后 Token 清除

### 6.3 登录失败处理
- [ ] 演示模式错误密码拒绝登录
- [ ] SaaS 模式错误密码拒绝登录
- [ ] 不存在的用户拒绝登录

---

## 七、边界与异常测试

### 7.1 权限边界
- [ ] 租户管理员访问 `/portal` 只能看到本租户
- [ ] 普通用户直接访问 `/portal` 被拦截
- [ ] 跨租户前台 URL 输入被正确拦截

### 7.2 状态异常
- [ ] 租户被停用后，用户无法登录
- [ ] 用户被停用后，无法登录任何入口
- [ ] 智能体实例停止后，用户仍可访问但收到提示

## 九、测试执行顺序建议

1. **模式区分验证** → 确认各入口正确识别
2. **登录流程验证** → 4 种用户分别测试
3. **权限隔离验证** → 跨角色、跨租户访问拦截
4. **主线功能验证** → 租户创建 → 用户创建 → 聊天
5. **异常场景验证** → 权限边界、状态异常
