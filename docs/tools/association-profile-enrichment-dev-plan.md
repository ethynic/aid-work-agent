## 验收目标

- 输入协会名称，可验证官网而非直接信任搜索结果；
- 从官网页面和附件提取字段，每个非空值都有 URL、原文引用、采集时间和内容哈希；
- 官网缺失手机时才调用微信 RPA；
- 搜索摘要不能写入最终字段；
- 冲突、失败和未公开可区分；
- 手机、邮箱及证据正文不出现在普通日志；
- 支持租户隔离、幂等重跑和人工复核。

第二次真实 Provider 联调中，模型为 `branch_count=16` 和
`organization_member_count=635` 返回了 JSON integer，唯一失败点是严格 schema
要求字符串。现仅在 schema 校验前将计数字段的非布尔、非负 JSON integer 转为
十进制 ASCII 字符串；浮点、负数、布尔值以及非计数字段的数值仍 fail-closed，
证据原文和来源 URL 校验保持不变。
