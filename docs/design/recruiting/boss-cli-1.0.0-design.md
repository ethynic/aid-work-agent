## 业务与开放命令

BOSS CLI 自己声明向 Agent 开放的业务命令、输入、过程结果和最终结果。内部小 CLI、翻页、候选人循环及单项失败处理由插件组织。涉及简历识别、评分和入库时，插件安排业务调用，授权及计费由对应云端业务接口处理。对外命令均声明串行。

具体命令名称、参数、结果字段、批次规模和内部组合在业务设计中确定。筛选长作业报告实际已处理、成功和失败情况，最终返回汇总。

## 运行条件与继续筛选

BOSS CLI 检查 Chrome 调试连接、目标 BOSS 页面、登录状态及命令所需的实际输入条件。复用已有页面、身份和动作确认。条件异常由插件返回明确原因、已知进度和最终状态。验收覆盖 Chrome 不可用、页面不符、未登录及输入条件不足，核对动作是否开始。用户打开的浏览器由插件按现有连接方式使用，Runtime 停止范围限于受管执行。

用户要求继续时，插件根据原作业保存的进度判断能否续筛及从哪里开始，保留已完成和已尝试但结果未知的记录。继续筛选的命令、引用参数和中断进度格式在本设计中确定。
