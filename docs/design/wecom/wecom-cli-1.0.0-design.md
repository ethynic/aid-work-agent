# WeCom CLI 1.0.0 设计

**业务命令清单待定，待开发。** 本轮与 Runtime 和 BOSS CLI 同步切换。[1.0.0 共同设计](../../system/runtime-plugin-1.0.0-design.md) · [实施计划](../../plans/plan-runtime-plugin-1.0.0.md)

## 业务与开放命令

WeCom CLI 自己声明插件身份、业务命令、参数、进度、结果及调度属性。桌面操作、内部命令及配置专用入口按实际调用范围登记。具备独立执行条件的后台命令由企微人工确认可并行，其余命令进入 Runtime 的统一串行队列。企微按自身业务步骤发起获准的云端调用，例如标定。

对外命令清单、完整业务作业边界、内部命令组合和云端服务授权在本设计中确定。

## 运行条件与验收

桌面操作由插件核对窗口、当前账号、目标和实际输入条件。本地库命令核对库可用性及账号归属。插件报告未登录、目标或窗口异常、数据库不可用等失败及已知进度。验收覆盖业务正常入口、桌面不可用时的明确错误，以及满足条件的独立后台读取。基础调度使用统一计划中的受控测试命令验证。
