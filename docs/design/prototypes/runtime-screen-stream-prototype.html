本原型覆盖的交互规则
  • 只有你在网页点「实时画面」才建立连接；平时 Runtime 不采集、不传画面。
  • 先建立不含画面的连接，Runtime 确认观看设备不是本机之后才开始采集。
  • 仅查看，不控制对方电脑。
  • 同一台电脑不能用：判定为同一台时提示并且不采集；无法确认时同样不采集。
  • 同一台 Runtime 同一时间只允许一个查看窗口。
  • 只做直连：能局域网直连或点对点直连就观看；都不通就提示「当前网络无法直连」，画面不经过服务器。
  • Runtime 端始终显示「正在远程查看」并可一键停止。
  • 目标电脑锁屏时画面暂停，解锁自动恢复。
  • 连续 30 秒收不到服务器确认，Runtime 自动停止共享；停的只是画面，不会去动这台电脑上的任务。
  • 画面端到端加密，服务器只负责牵线。
