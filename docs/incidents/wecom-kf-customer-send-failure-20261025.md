## 9. 排查经验备注

- sync_msg **不带 open_kfid 过滤会报 95000**（必须带 kfid 过滤）——排查时不要把这个 95000 误判为账号失效
- `servicer/list` 是 **GET 接口**（query 传参）——用 POST + JSON body 会报 **40058 missing field open_kfid**，不要误判为参数问题
- sync_msg body **多传 `token` 字段会报 95007**（生产代码不发该字段）——手工模拟请求时按生产参数构造，多余字段会引入误导性错误码
- 「客户发不出消息」需分层定位：客户端提交失败（红色感叹号）→ 腾讯系统内（sync 能拉到我方没消费）→ 我方处理（拉到但 processed=0）。本案是第一层；`processed_messages=0` 且消息仅为 event 时，不代表处理异常
- 诊断用的只读 API 组合：`gettoken` / `sync_msg`（全量时间线）/ `account/list` / `servicer/list` / `user/get` / `service_state/get` / `customer/batchget`
- session_id 客户段提取注意：格式 `tenant_{tid}_{channel}_{kfid}_{customer}_{subagent}`，tenant_id 本身含下划线，`split_part` 按 `_` 切会错位，用 `substring(... FROM 'wecom_kf_[^_]+_(wm[^_]+)')` 提取客户
