## 7. 排查经验备注

- sync_msg **不带 open_kfid 过滤会报 95000**（必须带 kfid 过滤）——排查时不要把这个 95000 误判为账号失效
- 「客户发不出消息」需分层定位：客户端提交失败（红色感叹号）→ 腾讯系统内（sync 能拉到我方没消费）→ 我方处理（拉到但 processed=0）。本案是第一层；`processed_messages=0` 且消息仅为 event 时，不代表处理异常
- 诊断用的只读 API 组合：`gettoken` / `sync_msg`（全量时间线）/ `account/list` / `servicer/list` / `user/get` / `service_state/get` / `customer/batchget`
