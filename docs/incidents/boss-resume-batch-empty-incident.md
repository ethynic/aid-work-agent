# BOSS 批量读简历「点不开/不保存」事故复盘

- **日期**：2026-09-10 发现，2026-09-11 根因定位与修复完成
- **环境**：正式环境客户「国腾」租户设备「曹老师-公司笔记本」（联想笔记本，小屏；device_id=53575923-5285-4061-8126-675127d559f0）
- **现象**：批量读取简历（boss_resume_batch）绝大部分卡片点击后页面毫无反应，详情打不开；偶尔打开的详情与卡片姓名不符（张冠李戴）；能打开的也没保存。开发机同代码一切正常。

## 时间线与关键事实

1. **09-10（0.2.11）**：两次批量 attempted=5 全部失败——4×「点击后详情未打开」+1×「姓名交叉校验未通过」。客户机 09-02 起就有同模式记录（每次 1 成功 4 失败），慢性问题。
2. **交叉校验拦下的是真错名**：0.2.9 回退测试把**王亦菲**的简历存到「任玮鹤」名下、**董云慧**的存到「田女士」名下（OCR 头部实锤）——0.2.11 的 P0 交叉校验（卡片姓名必须在 OCR 文本头部命中）拦下的是张冠李戴，不是回归。
3. **09-10（0.2.12，姓名点点击）**：能打开的都能正常入库了（3 份人卡对符），但打开成功率仍只有 ~1/5，且每批恰好 1 个交叉校验失败（点开的详情是别人的）+ 偶发「像素级同画面比对失败」（画布底部出屏裁剪越界）。
4. **09-11 根因实验**：同一会话、同一坐标——批量运行的 21 次点击全部被静默吞掉，而冷却后**间隔 20s 的单次 CDP 点击连续成功**。开发机重跑：批量偶发全败与单发成功并存。

## 根因

### Bug A「大部分点不开」：BOSS 反作弊 SDK 选择性拦截 CDP 合成点击

- 打开卡片详情此前走 **CDP 合成点击**（Input.dispatchMouseEvent，浏览器内事件）。开发机验证有效（08-17），但客户机/账号维度被 SDK 选择性拦截——被拦时点击静默失效，页面无任何反应。
- 佐证：同账号 **greet 的 Win32 真实鼠标点击一直正常**（Win32 为操作系统级真人输入，SDK 无法区分）；代码库 bossContext.ts 本就写明「BOSS 反作弊 SDK 选择性拦截 CDP 合成点击，写动作必须借真实光标」——打开卡片当年被归类为「浏览动作」用 CDP，只在开发机验证过。
- 拦截与账号/设备累计行为相关（客户机日常使用两周 vs 开发机偶测），表现为「越用越点不开」「先好后坏」；偶发被放行的点击在列表重排后落到别的行 → 开错人详情（交叉校验失败、以及 0.2.9 时代的错名入库）。
- 注：09-11 曾提出「点击/快照频率触发限流」的假说，被开发者正确质疑——同代码在开发机全中，频率不是充分条件；真正的变量是账号/设备维度的 SDK 拦截判定。批量失败期间页面残留的 546x273 画布（干净页面无）疑为被拦截后的降级弹层，身份未最终确认。

### Bug B「打开成功却不保存」：P0 姓名交叉校验正确拦截错名数据

0.2.11 非回归：能打开但内容对不上卡的详情，本就不该入库（错名简历会导致打招呼打错人，宁跳过不错存）。

### 小屏几何（次要，已修复）

画布矩形原样返回时底部出屏：小屏上弹层画布超出视口 → cv-segdiff/cv-stitch 裁剪越界报「像素级同画面比对失败」、滚轮落点出屏。修复为画布矩形与视口求交（裁剪/滚轮恒在可见区内）。

另：画布最小识别尺寸原为写死的 400px（历史：固定 600 曾误杀 572 高真实画布，08-18 改 400 仍是拍脑袋值）。弹层画布尺寸随窗口自适应，固定值在不同分辨率/缩放设备上不可靠。已改为**随视口自适应**：宽/高各 ≥ 视口对应边 ×25%，下限 200px 防图标 canvas。

## 修复（0.2.13）

1. **打开卡片改走 Win32 真实鼠标点击**（session.click）：坐标仍为配对姓名节点中心（DOM 配对，布局自适应），但事件通道与人工操作无法区分，SDK 拦截不再适用。CDP 浏览点击保留给弹层自愈（其被验证有效的场景）。
2. **画布矩形与视口求交**：修复小屏裁剪越界与滚轮落点出屏。
3. **日志保留**（0.2.12 引入）：[boss-batch] 逐卡点击序列/画布尺寸现场/批量汇总、[boss-op] 失败原因、[boss-ocr] 引擎决策、[runtime] 任务生命周期+回传 data_bytes、云端入库留痕——链路上任何节点失败均可从日志定位。
4. 批量全部未打开时，返回消息提示排查方向（避免被当成故障盲目重试）。
5. 曾按「频率限流」假说做的节奏/阈值改动（重击/卡片间隔拉长、快照降频、CANVAS_MIN 300）**已回退**到 0.2.11 值——开发机同代码全中证明频率非充分条件，避免无依据的降速。

**真机验证（开发机，Win32 点击）**：doctor 7/7 配对成功；`resume-batch --limit 3` 全部打开读取成功零失败（边海洋 3290 字、赵杰 639 字、李晓宝 7255 字，人卡对符，拼接图按姓名落盘）。
