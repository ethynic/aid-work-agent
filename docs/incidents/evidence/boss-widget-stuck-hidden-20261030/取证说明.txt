在原故障电脑上，用发生故障时的同一个 Windows 用户执行。

1. 解压附件到一个普通文件夹；不要在压缩包内直接运行。
2. 双击 run-collect-boss-evidence.cmd。
3. 等窗口显示 Created report。把同文件夹新生成的 boss-widget-evidence-*.json 发给排障人员。

不需要复现故障，也不需要先打开、关闭或重启 BOSS/Runtime。先保留当前记录，不清理临时目录。

采集程序只读当前用户临时目录中的 BOSS 目标绑定及 2026-10-30 10:40—11:20（北京时间）的视觉恢复记录，只输出必要的 ID、时间、页面路径、窗口标识/几何和有限状态。
不复制截图、候选人姓名、消息正文、职位、设备令牌、Cookie 或 Runtime 配置，不联网、不安装、不修改浏览器或 Runtime。启动器仅为本次 PowerShell 进程设置执行策略，不修改系统策略。

目录已被清理时，也会生成报告并记录 missing 或零条结果。这代表历史证据缺失，不代表故障没有发生。
请只发送生成的 JSON；不要打包整个 Runtime 目录或缓存目录。
