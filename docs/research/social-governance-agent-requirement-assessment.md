# 「社会治理智能体」技术要求评估

> 评估对象：客户提供的《技术要求》（社会治理智能体，面向高校教学实训场景，共 12 项）
> 评估日期：2026-11-03
> 评估结论：**约 60% 底层能力吻合、可投**；最大缺口为「可视化工作流编排」与「自助式知识空间」，投标前必须先定应对策略。

## 一、标书结构概览

| 序号 | 条目 | 性质 |
|------|------|------|
| 1 | 智能体开发系统平台（12 个子系统） | 平台能力 |
| 2 | 政策解读智能体（法规问答小助手） | 业务智能体 |
| 3 | 社情民意分析智能体（情绪识别 + 风险预警） | 业务智能体 |
| 4 | 企业问诊智能体（载体：工作流） | 业务智能体 |
| 5 | 公文校对智能体（载体：工作流） | 业务智能体 |
| 6 | 社会治理课程问答智能体 | 业务智能体 |
| 7 | 社工与志愿服务实务智能体 | 业务智能体 |
| 8 | 系统部署（本地私有化、50 亿 tokens/年赠送） | 交付 |
| 9 | 数据与信息安全 | 合规 |
| 10 | 知识产权及交付物（含教案/大纲/数据集） | 交付 |
| 11 | 测试与验收（单次响应 ≤10s、每类智能体 ≥20 用例） | 验收 |
| 12 | 培训与运维（质保 ≥3 年、终身小版本升级） | 服务 |

标书口径是**通用 Agent 开发平台**（类 Dify/Coze）+ 6 个教学场景智能体 + 私有化交付。本项目是企业员工智能代理 SaaS，定位有偏差但技术同源。

## 四、难度大 / 需重点决策

### 1. 可视化工作流编排（最大缺口）

拖拽画布 + 十几种节点（输入/输出/大模型/助手/技能/QA 检索/条件分支/代码/报告/MCP）+ 调试运行 + 版本管理 + 导入导出。

- 本项目是 AgentEngine 自主 Loop，**没有 DAG 执行引擎**，与现有架构理念不同
- 自研画布前端 + 节点执行器：2-3 人月起步
- ⚠️ 标书 2 个业务智能体（企业问诊、公文校对）明确写「载体：工作流开发搭建」，验收时可能被对照检查
- 应对策略：投标话术用「智能体 + 技能编排」等效承接，或外包/采购开源引擎（Flowise/Langflow 类）接入

### 2. 知识空间（第二缺口）

用户自助建空间、目录树、私有/需审核/公开三档权限、知识广场、加入审批、订阅。这是面向最终用户的协作产品，与本项目「管理员配置知识库 + 租户共享」治理模型差异大，约 1-2 人月。

降级方案：用现有跨租户共享（tenant_knowledge_shares）实现「公开 + 审批」两档。

### 3. 其他注意点

| 项 | 说明 |
|---|---|
| 音视频知识库（1024MB/文件，mp4/mov/avi/mkv 全格式） | ASR 工具已有；大文件分片转写 + 视频 keyframe 抽取没做过。验收大概率只测音频，建议按「音频转写入库」应答 |
| 本地私有化模型接入 | 网关支持 vLLM/Ollama 的 OpenAI 兼容口技术上 ~1 周；50 亿 tokens/年赠送是商务成本项，报价必须计入 |
| 教学配套材料 | ②④⑥⑦ 四个智能体都要求「实训指导文档/教学大纲/教案」，是文档交付工作量而非代码工作量，报价别漏 |
| 验收性能 | 单次响应 ≤10s + 每类智能体 ≥20 典型用例，需提前准备用例库与压测 |
| 质保承诺 | 质保 ≥3 年 + 终身小版本升级，商务条款需评估 |

## 五、结论

- **可投**：核心平台能力匹配度高，知识库 / 技能 / 工具 / MCP / 审计现成，6 个业务智能体中 4 个（政策解读、社情民意、课程问答、社工实务）是本项目强项场景。
- **投标前必须决策两件事**：
  1. 工作流编排：自研（2-3 人月）还是「智能体 + 技能」等效承接还是外采引擎（影响报价与验收风险）
  2. 知识空间：全量实现（1-2 人月）还是降级为共享授权模式
- 下一步建议：制作逐条点对点《偏离表》（正偏离/负偏离），工作流与知识空间按负偏离或等效替代写法处理。
