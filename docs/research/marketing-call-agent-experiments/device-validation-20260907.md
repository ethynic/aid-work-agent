## 权限与连接排查

1. 普通 USB 调试可截图，但最初 `input tap` 返回 255；一次诊断确认含 `SecurityException` 与 `INJECT_EVENTS` 权限错误。
2. 用户截图证实“USB 调试（安全设置）”已开启；`dumpsys package com.android.shell` 也显示 `INJECT_EVENTS: granted=true`。后续两次失败仅保留退出码，不能据此断言还是相同异常。
3. `adb reconnect` 后设备暂时消失；执行电脑端 `adb kill-server`、`adb start-server` 后恢复为 device，随后导航和拨号点击均返回 0。
4. 结论：本轮重启 ADB 服务后恢复；尚未证明根因，不能将其写成该机型必需步骤，也不应重复要求用户开启已经开启的开关。
