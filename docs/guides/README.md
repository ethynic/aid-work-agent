# docs/guides — 系统使用教程集中管理

本目录集中存放面向使用者/运维者的**教程、手册与指南**类文档，是 Portal「使用教程」文档中心（`/portal/guides`）的内容源。

## 收录范围

收录"教人怎么做"的操作性文档：

- 部署、发布、回滚、备份、组件配置等运维手册
- 渠道（钉钉/飞书/企业微信/微信客服等）接入与配置验证手册
- 客户端（Runtime、桌面客户端、业务 CLI 交付物）安装与打包手册
- 开发环境搭建、工具链与开发规范类指南

**不收录**：设计文档（`docs/design/`、`docs/system/*-design*`）、开发计划（`docs/plans/`）、调研报告（`docs/research/`）、故障复盘（`docs/incidents/`）、子智能体设计（`docs/subagent/`）、审计报告（`docs/audit/`）。环境实例档案（如 `deploy/生产环境部署.md`、济南诺度系列）保留在 `deploy/`，不进本目录。

## 分类

| 子目录 | 内容 |
|--------|------|
| `deployment/` | 部署与运维 |
| `channels/` | 渠道接入 |
| `clients/` | 客户端安装与使用 |
| `development/` | 开发环境与工具 |
| `operations/` | 管理操作（portal/租户管理员操作教程） |

分类的显示名与排序定义在 [manifest.yaml](manifest.yaml)，由后端文档中心 API 读取；新增分类需同步登记。

## 约定

1. **文档标题**：正文首个一级标题（`# `）即文档中心展示的标题，新增文档务必保留一级标题。
2. **收录动作**：新文档放入对应分类子目录即可出现在文档中心，无需另行注册；放入前先确认不含真实凭据（密码、密钥、令牌——本文档中心对平台管理员可见，但不应扩散凭据）。
3. **引用更新**：移动本目录文档时，必须全仓搜索旧路径并更新引用（含 AGENTS.md、规则文件、脚本注释与文档间相对链接）。
4. **相对链接**：文档间链接使用相对路径；指向仓库其他位置的文件时按 `../../` 相对路径书写。
