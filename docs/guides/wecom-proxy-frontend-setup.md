# 企业微信代理任务与每日总结：前端配置教程

本教程适用于已部署企业微信代理功能的租户。代理任务在指定会话收到新消息后调用所选智能体回答；每日总结使用独立的手动或定时流程，不加入代理回复队列。

## 一、先准备本机设备

1. 在 Windows 电脑登录企业微信，并保持电脑未锁屏。启动已安装的 AID Work Runtime，确认企业微信插件显示“已启用”“已就绪”，Runtime 显示“已连接企业服务”。
2. 在网页打开**连接中心 → 本地工具**。尚未配对时，点击“生成配对码”，在 Runtime 中输入配对码。已配对时，在“我的设备”找到这台在线设备，点击“选定”；它的“当前设备”列应显示“使用中”。
3. 后续创建代理任务会绑定这台已选设备和它当前登录的企业微信账号。页面创建时会通过 Runtime 实际执行 CLI doctor 和双坐标标定；检查失败时任务不会保存，按页面错误先修复本机登录、插件或连接状态。

## 二、建立代理任务

1. 打开**连接中心 → 企业微信代理任务**，点击“＋ 新建代理任务”。
2. 未登记的会话先到**连接中心 → 企业微信每日总结**，点击“＋ 添加会话”从本地目录登记。回到代理任务表单，填写容易辨认的“任务标题”，点击“从本地目录选择会话”，搜索并勾选已登记的单聊或群聊，然后点击“完成选择”。可多选，最多 50 个；同名会话要核对类型、来源平台和页面显示的会话短 ID，确保选中正确对象。
3. 在“智能体”中单选一个当前租户有权限的智能体。代理回答由该智能体执行，不需要再到智能体配置里手动添加企业微信 CLI 工具或相关 Skill。
4. 填写“任务指令”（最多 5000 字），说明该任务应该回答什么、什么情况不回复、需要遵守的业务口径。它只用于本任务的回答。例如：`监控所选客户单聊。回答商品和售后问题；价格、库存、订单状态未经核实不要编造。无法确定时说明需要人工核实。`
5. 点击“创建任务”，等待页面完成设备与账号真实检查。新任务初始为“已停止”；检查详情中的设备、企微账号、智能体和会话目标，再点击“启动”。首次启动会以当时会话消息建立基线，此后新消息才进入回答批次。

## 三、检查代理是否工作

从被监控的微信/企业微信会话发送一条**启动后**的新消息。回到任务列表或点击“详情”：

- “运行中”表示监控已启动；“最近检查”“最新消息”“空闲读取”反映监控进度。没有新消息时，空闲读取可以增加，但不会因此创建回答 Runner。
- “会话目标”中的“已处理位置”表示已经完成的入站消息位置；“最新消息”表示最近读到的位置。两者可能暂时不同，因为新消息可在回答时继续到达。
- “批次记录”会显示回复文本、关联的入站消息、Runner、积分和 CLI 回执。看到“本机客户端已记录发送”、回执编号与本地库消息编号，表示客户端用本地记录核验了发送；如需确认微信侧实际收到，请同时查看对方聊天窗口。
- 若智能体判定无需回复，批次会显示“本批判定无需回复”。失败时看批次的 CLI 错误、会话目标停住原因和 Runner 编号；不要对结果不明的发送手动重复发送。

需要改标题、会话范围或任务指令时，先点“停止”，待当前批次结束且任务变“已停止”再点“编辑”。重新“启动”会从保存的会话位置继续；更换 Runtime、企微账号或智能体需新建任务。删除是软删除；勾选“显示已删除任务（只读）”仍可查看历史结果。

## 四、配置企业微信每日总结

1. 打开**连接中心 → 企业微信每日总结**。在“今日”的“本次总结的会话”处点击“＋ 添加会话”，从当前已选设备的本地目录勾选会话并确认。可用“全部会话”或逐个勾选决定本次手动总结范围。
2. 要立即生成今日内容，点击“更新对话总结”。页面按会话显示概览、待办及失败原因；“查看执行记录”可查看每次执行及诊断信息。昨日和更早日期用于查看已保存报告，不提供手动更新入口。
3. 要自动生成，点击“定时执行配置”。选择总结“前一天”并设置每天的北京时间，或选择“今天”并设置每隔 1–24 小时；再选“动态全部会话”或“自选会话”，点击“保存配置”。抽屉会显示下次预计执行时间。已建计划可在这里“暂停”或“恢复”。

每日总结与代理任务互相独立：添加日报会话不授权自动回复；停止代理任务也不会移除日报中已添加的会话。
