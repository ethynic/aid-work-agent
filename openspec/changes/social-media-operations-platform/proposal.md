# 社媒内容运营智能体与聚合平台

## 背景

现有系统缺少面向租户的社媒运营闭环。运营人员需要在多个平台间维护账号、计划、内容版本、审核、发布任务和运营数据，且发布动作必须可审计、可追溯、不可由 LLM 绕过审核。

## 范围

- 新增 `/api/social-media` 前后端契约。
- 新增社媒账号、计划、内容母版、平台版本、审核记录、发布任务、发布结果和指标快照的数据模型。
- 新增平台连接器协议和能力解析，首期注册微信公众号与微信视频号辅助连接器骨架。
- 新增聚合工作台页面 `/social-media` 与租户路径 `/t/:tenant_id/social-media`。
- 新增社媒运营子智能体定义，明确不能查看凭证、不能自动审批、不能直接发布。

## 非目标

- 不实现视频号非官方接口、Cookie 托管或 RPA 发布。
- 不把平台接口受理显示为 API 已发布成功。
- 不在未完成真实账号验证前标记微信公众号真实发布闭环完成。

## 影响

- 新增业务表，所有表包含 `tenant_id` 并由服务层强制过滤。
- 新增 API 路由和前端页面。
- 新增可插拔连接器边界，后续平台通过连接器扩展，不修改核心状态机。
